# 事前登録：旗144「**骨格の r に、年の対比はどれだけ混ざっているか**」（旗143 の宿題）

**この測定の結果はまだ一つも見ていない。**（28 回目の事前登録。）
**見たのは旗143 の `ES-FcO`（3 年）の結果だけ**であり、
**旗88/89/91/106/107 の r を年で分けて計算したことは一度もない。**

---

## なぜやるか（旗143 で分かったこと）

旗143 は `ES-FcO`（**3 年**）で、報告していた `r̂ = −0.224`（MAM）・`−0.283`（SON）の**大半が
「年をまたぐ対比」だった**ことを示した——**年ダミーを除くと `−0.039` / `−0.199` に落ちる**。
**年の対比はたった 3 点の相関**であり、偶然でいくらでも大きくなる。

**同じ汚染が骨格（旗88/89/91/106/107 ＝ US-Wkg・US-Whs・US-SRM・モンゴル 3 サイト）にも
乗っていないか。** これらは **18〜22 年**あるので**効かない公算が高い**が、**測っていない。**
**測るまで骨格に何も書き足さない・書き換えない**（旗143 が自分に課した条件）。

## 測るもの（**一つだけ**）

各土俵・各サイト・各季節・各半分（θ→γLE｜Rg と θ→γH｜Rg）について：

- **`r_raw`** ＝ 現行の偏 Spearman（Rg のみ除去）＝**これまで報告してきた値**
- **`r_yr`** ＝ **Rg に加えて年ダミーも除去**した偏 Spearman（旗143 の `nullwhy` と同じ実装）
- **`d = r_yr − r_raw`** ＝ **年の対比が `r̂` に足していた分（符号つき）**
- **分解**（恒等式）：Rg を除去した順位残差を年内成分と年平均成分に分け、
  **`r_raw = r_between + r_within`** を厳密に成り立たせて両者を印字する
- **Δ = r_秋 − r_春** についても同じく `Δ_raw`・`Δ_yr`・`d_Δ` を出す（旗91/107 の主判定量）

**新しい検定はしない。CI も p も出さない**——**測るのは「ずれの大きさ」だけ**である
（旗139 で CI の被覆が標本規模に依ることが分かっており、**較正していない CI は出さない**）。

## 門①（対照）——**実データより先に走らせる。合成で 3 本**

**穴 #70 の反省に従い、向きだけでなく「これ以上／これ未満」を必ず添える。**

| 対照 | 作り | **合格条件（先に固定）** |
|---|---|---|
| **G1 `within_only`** | 年内にだけ真の連関（β<0）・年平均は θ と γ で独立に振る／**20 年**・200 反復 | **`\|d\|` の中央値 < 0.03**（＝年除去は本物の年内信号を壊さない）**かつ `r_raw` 中央値 < −0.15** |
| **G2 `between_only`** | 年内の連関は 0・**年平均どうしにだけ**真の関係／**3 年と 20 年**・200 反復 | **両方で `d` の中央値 ≥ +0.10 かつ `\|r_yr\|` 中央値 < 0.05**（＝本物の年間関係は年数によらず検出され、除去後は 0 になる） |
| **G3 `no_between_signal`** | 年内に真の連関・**年平均は独立**（＝年の対比は偶然だけ）／**3 年と 20 年**・200 反復 | **`d` の SD が 3 年 ≥ 3 × 20 年 かつ 20 年の SD < 0.05**（＝偶然の年対比は年数で薄まる） |

**3 本とも合格しなければ実データに進まない**（旗52 の作法）。
**G3 が落ちたら「年数が多いから安全」という読み自体が成り立たない**ので、そう書く。

## 判定規則（**数字を見る前に固定**）

下限は既存と同じ：**日数 ≥ 60・年数 ≥ 3**。満たさないセルは**判定しない**（数だけ数える）。

セルごと：

- **`|d| < 0.05`** → **無視できる**
- **`0.05 ≤ |d| < 0.15`** → **効いている（併記が要る）**
- **`|d| ≥ 0.15` または `r_raw` と `r_yr` で符号が変わる** → **骨格に触る**

集計（**判定できたセル全体**で）：

1. **「骨格に触る」が 0 かつ「効いている」が 0** →
   **結論：骨格の r は年の対比に依っていない。旗88/89/91/106/107 の記述は変えない。**
2. **「骨格に触る」が 0 で「効いている」が 1 件以上** →
   **該当セルを名指しし、`FLAGS_LOG` と `SESSION_STATE` に「そのセルの r には年の対比が d だけ乗る」と併記する。**
   **判定そのものは変えない。**
3. **「骨格に触る」が 1 件以上** →
   **該当する主張に注記を入れ、`MEASURED_ONLY_SPINE.md` の該当行を「要再検討」として GATE ではなく
   次の事前登録の対象に登録する。** **本周では判定を差し替えない**
   （**結果を見てから統計量を差し替えない**＝旗143 の穴 #69 で自分に課した規則）。

**Δ についても同じ 3 段階を当てるが、`Δ` は差なので `d_Δ` の閾値も同じ 0.05／0.15 を使う。**

## この測定で**言えないこと**（先に書く）

- **年ダミーを除いた r が「正しい r」だとは言わない。** どちらも別の問いに答えている
  ——**生の r は「日と年をまとめた連関」、年除去の r は「年内の連関」**である。
- **年の対比が大きいことは、それ自体では誤りではない。** **誤りは「年内の連関」と読むことである。**
- **本測定は季節差の実在を再判定しない。** 旗88/91/107 の判定はそのまま残る。
