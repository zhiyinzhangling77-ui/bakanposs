## なぜこれをやるか（旗125 が残した宿題の第一候補）

**旗125 は旗44 の `d`（`Tc·θz` の係数）の識別可能性を測り、θ–T 相関 −0.95 で被覆率 77% まで落ちることを見た。
だがあの合成の雑音は `rng.normal(0, 0.15, n)` の iid であり、時間方向の自己相関が一切ない。**

**旗44 の CI は `_boot_d`（`block = 48*7 = 7 日`）のブロックブートで作られている。
ブロックブートが存在する理由は残差の自己相関である。
＝旗125 は「ブロックブートが本来相手にしている当のもの」を一度も入れずに被覆率を測った。**

**実測の 30 分刻みの土壌呼吸は、モデルで説明し切れない残差が数時間から数日のスケールで持続する
（雨イベント・基質の供給・センサのドリフト）。** **この自己相関があると、独立標本を仮定した CI は
真の標本分布より狭くなる。ブロックブートはそれを吸収する設計だが、
旗44 では一度も「吸収できているか」を確かめていない。**

**もし吸収できていなければ、旗44 の ★ 18/36 の一部は自己相関による過小な CI の産物でありうる**
——**旗125 が「★ は水増しされない」と結論した根拠（偽 ★ の期待 1.8/36）は、iid 雑音のもとでの数である。**

## 問い

**水分が温度感度に一切効かない（真の `d = 0`）合成において、
残差が AR(1) で自己相関しているとき、旗44 の判定手続き（`analyze` ＋ ブロックブート 95% CI）は
名目の被覆を保つか。それとも ★（偽陽性）を出すか。**

## 手順（先に固定する）

1. **道具は旗44 のものをそのまま import して使う**（`analyze`・`_boot_d`・`_design`）。
   **再実装しない。しきい値も `nboot=200` も `block=48*7` も一つも変えない。**
   **合成の生成器は旗125 の `synth` をそのまま使い、`lnR` に載る観測雑音だけを AR(1) に差し替える。**
2. **AR(1)**：`ε_t = φ·ε_{t−1} + η_t`、`η ~ N(0, σ√(1−φ²))`、`σ = 0.15`（旗44 と同じ）。
   **周辺 SD を φ に依らず 0.15 に固定する**——**固定しないと雑音の大きさ自体が水準間で動き、
   被覆率を比べられない**（旗125 で `Var(θ)` を固定したのと同じ理由）。
   **初期値は定常分布から引く**（立ち上がりの過渡を入れない）。
3. **水準**：**φ = 0 / 0.5 / 0.9 / 0.98**（30 分刻みでの e-fold ≒ 0 / 0.7 / 4.7 / 24.7 時間）を
   **θ–T 相関 ρ = −0.5 に固定して**振る（**旗44 既定の合成が実現していた水準**）。
   **＝自己相関の効果を、旗125 が見た共線の効果から切り離して測る。**
   **加えて交差セルを 1 つだけ置く**：**(ρ, φ) = (−0.85, 0.9)**
   ——**共線と自己相関が同時に効くときに、片方ずつの結果から予想が付くかを見る**（**補助・主判定には使わない**）。
4. **各セルで 2 本の腕**：
   - **帰無腕**：真の `d = 0`（水分は「量」を変えるが「感度」は変えない）
   - **陽性対照腕（門①）**：**真の `d` を、そのセル自身の判定境界の 3 倍に較正する**（下記）
5. **★対照の較正（旗125 の欠陥 #46 の是正）**：
   **旗125 の対照は真の d が判定境界の約 26 倍で、どの水準でも検出率 100% になり、
   「検出力が落ちる水準」を捕まえられなかった。**
   **本旗では、各セルごとに帰無腕のパイロット（20 反復）を先に走らせ、
   `CI 幅の中央値 / 2`（＝そのセルの判定境界）を測り、対照の真の `d` を**その 3 倍**に置く。**
   **＝欠陥 #46 が指示した「1〜3 倍」の上端。** **セルごとに較正するので、
   自己相関で CI が広がった水準では対照の効果量も同じ比で大きくなる**
   ——**門①が「自己相関で検出力が落ちた」ことを理由に落ちるのを防ぐためである**
   （**落とすべきは「手続きが自己矛盾しているセル」だけ**）。
   **較正に使うのは帰無腕の CI 幅だけであり、主判定の量（被覆率・★率）は一切見ない。**
   **測った境界と対照の真値は、セルごとに全部印字する。**
6. **反復 R = 100**（各腕・各セル）。`n = 20000`（30 分刻み・暦順＝約 417 日）。
7. **落ちた反復は理由ごとに数える**（旗108・欠陥 #40）：`当てはめ崩壊`・`CI 不定`・`点不足`・`生成不能`。
   **被覆率と ★率は「CI が出た反復」を分母に取り、落ちた本数を必ず併記する。**
8. **補助の対照実験（判定に使わない）**：**同じ反復で `block = 1`（＝iid ブート）の CI も作り、
   被覆率を並べて印字する。** **ブロックブートが仕事をしているかを、直接見るためである。**

## 判定規則（**結果を見る前に固定**）

**主判定は帰無腕の 2 つの数**：**被覆率**（CI が真値 0 を含む割合）と **★率**（`ci[0] > 0` の割合）。
**対象は ρ=−0.5 の 4 セル**（交差セルは補助）。

| ρ=−0.5 の 4 セルでの結果 | 結論 |
|---|---|
| **すべての φ で ★率 ≤ 5% かつ 被覆率 ≥ 90%** | **○ブロックブートは自己相関を吸収できている**——旗44 の CI は残差の自己相関に対して頑健 |
| **★率 > 5% または 被覆率 < 90% が 1 水準だけ、かつ ★率 ≤ 8%** | **▲弱**——断定しない。**その水準以上の自己相関を持つ実サイトは要再点検** |
| **2 水準以上で ★率 > 5% または 被覆率 < 90%** | **▲ブロックブートは吸収し切れない**——**旗44 の 18/36 は自己相関の強いサイトで水増しされている可能性がある。「可能性がある」までしか書かない**（実サイトの残差 ACF1 が未確認のため・上記「前提」3） |

**門①（陽性対照）**：**各セルで陽性対照腕の検出率（★率）が 80% 以上あることを確かめる。**
**80% 未満のセルは、帰無腕の結果を「偽陽性が無い」の証拠に使わない**（旗95 の欠陥 #31 と同型の罠）。
**★較正どおりなら（真の d ＝ 境界の 3 倍）、手続きが自己矛盾していないセルでは検出率は 95% を超えるはずである。
80% を割るセルが出たら、それ自体が「CI 幅とばらつきが噛み合っていない」証拠として報告する。**

**補助として記録するが判定には使わない**：`block=1` の被覆率・★率／CI 幅の φ 依存／
`d̂` の中央値（偏り）と SD(d̂)（分散）／実現 ACF1／VIF／交差セル。

## 予測（**旗102 の作法：結果を見て旗44 の判定規則は変えない**）

**H1（主・勝敗に数える）**：**○——★率は全 φ で名目内（≤5%）にとどまり、被覆率は 90% 以上を保つ。**
根拠：**AR(1) の相関長（φ=0.98 で e-fold ≒ 50 刻み）はブロック長 336 刻みよりずっと短く、
ブロックは相関構造を丸ごと内側に含む。** **効果は CI 幅として現れ、
`√((1+φ)/(1−φ))` の目安で φ=0.98 では 10 倍前後に広がる。**
**さらに旗125 で被覆を落としていたのは分散膨張ではなく `d̂` の負のバイアス（LT が厳密に二次でないため）で、
そのバイアスは φ に依らず一定である。CI だけが広がるので、被覆率は φ とともに 91% から改善する側に動く。**

**H2（補助・勝敗外）**：**`block = 1` の iid ブートは φ=0.9・0.98 で被覆率が 50% を割る**
＝**ブロックブートは仕事をしている。**

**H3（補助・勝敗外）**：**交差セル (−0.85, 0.9) の被覆率は、旗125 の (−0.85, φ=0) の 89% より高い**
（CI が広がる分、バイアスの相対的な重みが下がる）。

**これは統計からの予測であり、勝敗に数える：16 回目・現在 15 回中 8 勝。**

**H1 が外れる（★率が上がる／被覆が落ちる）としたら最もありそうな筋**：
**`_boot_d` は `nblk = n // block` 個のブロックを**復元抽出**で並べるので、
同じ区間が重複して入り、ブロック境界で人為的な不連続が生じる。
自己相関が強いほどブロック内の情報量は減るのに、
再標本の長さは常に n に固定されるため、**ブートが「実効標本サイズの減少」を過小評価**しうる。
その場合 CI は真の標本分布より狭くなり、被覆は落ち、★ と × の両側に外れが出る。**確からしさ：中。**
**この筋を見分けるために、`SD(d̂)`（反復間の真のばらつき）と `CI 幅/3.92`（ブートの推定するばらつき）を
並べて印字する**——**両者の比が 1 から離れれば、ブートの側が原因である。**

## 事前に認めておく限界

- **これは道具の点検であって、新しい科学的主張ではない。**
  **`MEASURED_ONLY_SPINE.md` の土俵分け・数値・スコープは、この旗では一切動かさない。**
- **AR(1) は自己相関の一形態にすぎない。** 実測の残差は**日周期**と**雨イベントの跳ね**を持ち、
  AR(1) では表せない。**「AR(1) で保つ」は「実データで保つ」ではない。**
- **温度の雑音 `ε_T` は iid のまま**（旗44・旗125 と同じ生成器を保つため）。
  **実測では気温の残差も自己相関する。** **駆動側の自己相関の効果は測っていない。**
- **実サイトの残差 ACF1 の分布は未確認**（この周は `/mnt/hdd` が無い）。→ **GATE-22。**
- **反復 100・水準 4 は、5% と 8% の差を確実に分ける精度を持たない。**
  **「▲弱」の欄を先に用意したのはそのためである。**
- **較正パイロット（20 反復）の中央値には誤差がある。** 対照の真値が名目 3 倍から前後する。
  **測った値を印字するので、事後に確認できる形にはしてある。**

## ★追補（**動作確認の後・判定の実行の前**に足した。理由も含めて全部書く）

**上の設計で反復 3・n=20000 の動作確認を走らせたところ、`CI 幅` が φ にほとんど反応しなかった**
（φ=0 を 1.0 として 0.5→1.1・0.9→1.0・0.98→1.1。`SD(d̂)` も 0.000119→0.000141 しか動かない）。
**φ=0.98 は実効標本サイズを 100 分の 1 にする水準であり、この鈍さは「合成の側の性質」である。**

**原因**：**旗44/125 の生成器では θ の雑音が iid なので、回帰子 `Tc·θz` が白い。**
**白い回帰子は赤い誤差とスペクトルがほとんど重ならず、`(X'X)⁻¹X'ΣX(X'X)⁻¹` の中央項が
ほぼ `σ²X'X` に戻る**——**＝自己相関があっても推定量の分散は膨らまない。**
**この設計のままでは「ブロックブートの必要な状況」を一度も作れておらず、
○が出ても『自己相関に頑健』の証拠にならない**（**旗91 の「ほぼ必ず通る検定」と同型**）。

**実測の土壌水分は 30 分刻みで強く自己相関する**（連続な状態量であり、雨で階段的に上がって
数日かけて乾く）。**＝旗44 の実データでは回帰子は赤い。**

**足すもの**：**θ の雑音も AR(1) にした軸**（`φ_θ = 0.99`＝e-fold 約 100 刻み＝約 2 日）。
- **周辺分散は `φ_θ` に依らず保たれる**ので、`Var(θ)` も `corr(θ,T)` も期待値としては動かない。
- **セル**：`(ρ=−0.5, φ=0/0.9/0.98, φ_θ=0.99)` の 3 つ。**交差セルにも φ_θ=0.99 版を 1 つ足す。**
- **事前登録の軸（φ_θ=0）は 1 セルも削らない。** **両軸を並べて報告する。**
- **判定規則は両軸で同一**（上表・門①・5%/8%/90% の線は一切動かさない）。
- **回帰子 `Tc·θz` 自身の ACF1 を印字する**——**「赤くなった」ことを数値で確かめてから読む**
  （旗104/106 の作法＝腕が名乗る性質を実際に持つことを確かめる）。

**両軸が食い違ったときの読み方（結果を見る前に決める）**：
**事前登録された判定は軸1（白）である。だが実データに近いのは軸2（赤）である。
どちらか一方だけを書かない。両方を書き、「結論は回帰子の自己相関に依存する」と述べる。**
**軸2 で破れた場合も「可能性がある」までしか書かない**（実サイトの ACF1 が未確認・GATE-22）。

**予測の扱い**：**H1 は軸1（事前登録どおりの軸）で判定する**（後から足した軸で勝敗を決めない）。
**軸2 についての予測をここで別に書いておく**——**H4（補助・勝敗外）：軸2 では CI 幅が φ とともに
明確に伸び（φ=0.98 で数倍）、そこで初めてブロックブートが試される。被覆は保たれると見るが、
確からしさは H1 より低い**（**ブロック内の実効情報量の減少をブートが過小評価する余地が、
回帰子が赤いときに初めて出るため**）。

**この追補は「結果を見てから規則を変えた」のではない**——**動かしたのは合成の設計（水準の追加）であり、
判定規則ではない。かつ、見たのは動作確認 3 反復の CI 幅であって、判定に使う被覆率・★率ではない。**
**それでも後から足したという事実は残るので、ここに明記する。**
