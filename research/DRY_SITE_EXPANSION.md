# 乾燥サイトを増やす計画——そして、これは穴②も同時に埋める

## 指摘は正しい：いま乾燥フラックスは実質1地点しかない

水マスター（θ→蒸発の支配と Bowen 反転, A-3）は **MN-Hst / MN-Nkh / MN-Kbu の3サイト**で示したが、
旗43 のクラスタ縮約で **50km 以内＝1クラスタ＝独立地点 n=1** に潰れた。
＝効果量は最も堅いのに、**一般化の土台がほぼ無い**。これは自分で認めながら**手を打っていなかった**穴である。

## 突破口：AmeriFlux の乾燥地サイトは、COSORE のチャンバーと同じ場所にある

COSORE の乾燥地チャンバーには **`SCOTT_WKG` / `SCOTT_WHS` / `SCOTT_SRM`** がある（旗57/61 で使用）。
検索で確認した範囲では、**US-Wkg（Walnut Gulch Kendall Grasslands）は Russell Scott が提供する
AmeriFlux の渦相関サイト**であり（EC 観測は 2004 年春から）、COSORE の `SCOTT_WKG` と
**同一研究者・同一サイト名**である。US-Whs（Walnut Gulch Lucky Hills Shrubland）・
US-SRM（Santa Rita Mesquite）も同様の対応が期待される。

**※要確認**：同一地点であることは、**COSORE の座標（我々は保持済み）と AmeriFlux のサイト座標を
突き合わせて確認する**こと。名前と研究者が一致しても、同一地点とは限らない（旗51 で 10km 基準を用いた）。

### これが同時に埋める2つの穴

| 穴 | いまの状態 | AmeriFlux 乾燥地サイトを足すと |
|---|---|---|
| **水マスターの独立地点 n=1**（旗43） | モンゴル3サイト＝1クラスタ | **北米半乾燥地が加わり、独立クラスタが増える**＝一般化の土台ができる |
| **② 同一サイトでタワー＋チャンバーが無い**（旗51 で10km以内に一組も無いと確認） | 外部連絡が要ると結論 | **同一地点でタワーとチャンバーが揃う**＝弧が閉じる。**外部連絡なしで** |

＝**旗51 で「手元では閉じない」と結論したのは、手元のタワーが日本のサイトだけだったから**であり、
**タワー側を増やせば閉じる**。この可能性を検討していなかったのは私の見落としである。

## 具体的な手順

1. **AmeriFlux でデータ利用登録**（AmeriFlux Data Policy への同意が要る）。
2. 対象候補（乾燥・半乾燥）：
   - **US-Wkg**（Walnut Gulch Kendall Grasslands, 半乾燥草原）
   - **US-Whs**（Walnut Gulch Lucky Hills Shrubland, 半乾燥低木地）
   - **US-SRM**（Santa Rita Mesquite, 半乾燥サバンナ）
   - 余力があれば US-Ses / US-Seg（Sevilleta 草原・低木地）, US-Var（カリフォルニア草原）など
3. **BASE 形式（30分値）**でダウンロードする。**本リポジトリは BASE 形式に既に対応済み**
   （`japanflux_pn/sites.py` の `DEFAULT_VAR_MAP_BASE` / `hh_glob="**/*BASE_HH_*.csv"`）。
   ＝**コードの改修はほぼ不要**で、サイト登録だけで既存の旗31/36/37 がそのまま走る。
4. 置き場所：`/mnt/hdd/AMERIFLUX/<SITE>/` などに展開し、`sites.py` に登録する。
5. **座標を突き合わせて同一地点を確認**してから、旗51 を再実行する（10km 基準）。

## 期待できること（過大に言わない）

- **水マスター**：北米半乾燥地でも θ→γLE>0 かつ θ→γH<0（Bowen 反転）が出れば、
  **独立クラスタが 1 → 2 以上**になり、旗43 の族補正で初めて「反復のある主張」になる。
  出なければ、**モンゴル固有の現象**だったと分かる＝どちらでも前進。
- **穴②**：同一地点でタワーの GER 残差メモリとチャンバー Rs のメモリを並べられる。
  ただし**乾燥地は森林ではない**ので、旗57 の結果（~4日帯は森林の現象）からすると
  **メモリ自体が出ない可能性が高い**。＝弧を閉じるには**森林の同一地点**が本命で、
  乾燥地は「水マスターの一般化」が主目的、と分けて考える。
- 森林で同一地点を狙うなら、COSORE の森林チャンバーに対応する AmeriFlux/ICOS タワー
  （例：Harvard Forest の SAVAGE 系、Morgan Monroe の DESAI/VARGAS 系、Ontario の ARAIN 系）を
  同様に確認する価値がある。**旗51 を「手元のタワー」でなく「COSORE 側から逆引き」してやり直す**のが筋。

## 記録

- 本計画は**データ取得を要する**ため、実行はユーザーの判断。
- 取得後は `sites.py` への登録と座標突き合わせ（旗51 再実行）から始める。
