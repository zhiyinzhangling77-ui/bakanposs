## 先に事実——欠陥 #78 の中身（旗146・ログ `step144_20260909_173142.txt`）

追補 C の判定量は

    t = − sign(r_within) × r_raw

**`sign(r_within)` が向きの基準**である。**基準が決まらなければ `t` の符号は決まらない。**

**旗146 で反転ルートから骨格に残った 2 セルの `|r_within|` は 0.071 と 0.018** ——
**年内の連関がほとんど無い。** `t` は `r_within` が 0 に近いと実質 `− sign(r_within) × r_between` になり、
**片側の向きをほぼ雑音が決める。** しかも**片側**なので、追補 B の両側 `p`（0.0667・0.1292）が
落としたセルを拾う。**2 セルとも、この隙間に入っている。**

## ★この追補が何を直し、何を直さないか（**誇張しないために先に書く**）

**直さないもの：偽陽性率。** 追補 C の門① G1''' は 9 条件すべてで 0.000〜0.050 ≤ 0.10 だった。
**＝合成の上では、追補 C の反転ルートは較正されている。追補 D はそれを改善しない**
（むしろ検定を厳しくするので下がるが、それは目的ではない）。

**直すもの：主張の意味。** `r_within` が 0 と区別できないセルでは、

**「意味が定義できない道を骨格と数えない」まで広げるのが本追補**である。

**だから本追補の門①の本丸は「偽陽性が下がるか」ではなく、

## 足すもの——`within_shuffle`（**年内成分の帰無**）

### 帰無の作り方

`yw`（γ の年内成分）を、**年の中だけで**日ラベルごと並べ替える。

- `yb`（年平均成分）は動かない → **`r_between` も `vshare` も不変。**
- 分母 `sy = sqrt(mean(yb²) + mean(yw²))` も**不変**（並べ替えは二乗平均を変えない）。
- **動くのは分子 `mean(xw·yw)` だけ**＝壊すのは「同じ日の θ と γ の結びつき」だけである。

並べ替え `σ`（年内のみ）ごとに

    r_within^σ = mean(xw · yw[σ]) / (sx · sy)

**両側 `p_within`** を取る（年内の連関は向きを問わない・反転の向きの基準が「0 でない」ことだけを問う）：

    p_within = (1 + #{ |r_within^σ| ≥ |r_within_obs| − 1e-12 }) / (1 + nperm)

### `nperm = 1000`（**追補 B/C の 5000 と違う。理由をここに書く**）

**日の並べ替えは年の並べ替えより桁違いに重い**（年は 20 個、日は数百〜数千個）。
**`p` の分解能は 0.001 で、判定に使う境 0.05 からは十分離れている。**
**これは精度の妥協であり、判定規則の緩和ではない**——`nperm` を増やしても境は動かない。
**`nperm` は実データと門①で同じ値を使う**（較正した手続きと当てる手続きを一致させる）。

### 適用範囲

**全セルで計算して印字する**（反転セルだけでなく）。
**理由：欠陥 #78 は「`|r_within|` を判定の隣に印字していなかった」ことから生まれた。**
**判定に使わないセルでも並べて出す。** ただし**判定を変えるのは反転ルートだけ**である。

## 判定規則（**反転ルートだけを差し替える**・他は追補 C のまま）

| 条件 | 判定 |
|---|---|
| `k < 6` 年 | **判定しない**（追補 C のまま・#75） |
| `p < 0.05` かつ `\|r_between\| ≥ 0.15` | **骨格**（**触らない**） |
| `p < 0.05` かつ `\|r_between\| < 0.15` | **効く**（**触らない**） |
| **反転（`t_obs > 0`）かつ `p_within ≥ 0.05`** | **判定しない**（★ここが新しい） |
| **反転 かつ `p_within < 0.05` かつ `p_flip < 0.05`** | **骨格**（追補 C の道・前段を通ったもの） |
| 反転 かつ `p_within < 0.05` かつ `p_flip ≥ 0.05` | **偶然の水準と区別できない**（追補 C のまま） |

**★「偶然」ではなく「判定しない」に落とす理由**：`p_within ≥ 0.05` は
**「年内の連関が無い」ではなく「向きを決められない」**である。
**向きが決まらないセルについて、反転が偶然かどうかを本追補は何も言わない**
——**言えないものを「偶然と区別できない」と書くと、測ったふりになる。**

**`|r_within|`・`p_within`・`t_obs`・`p_flip`・`vshare` を必ず並べて印字する。**
