# 事前登録 旗91 の**追補**：主検定を「春と秋の差を直接ブートストラップする」に変える

**実データにはまだ触れていない。** 本追補は `PREREGISTRATION_step91.md` を commit した後、
**合成データで道具を検証した結果**として書き、**実データ実行の前に commit する**。
**元の文書は書き換えない**（旗62 以来の作法。旗89 でも同じことをした）。

## 合成検証で分かったこと：**元の検定はほぼ必ず通る＝証拠にならない**

事前登録どおり合成で検証した。**検証の仕方を 2 度作り直し、2 度とも失敗した**：

1. **`power_only`（春秋を同じ強さの強い効果に）** —— **春も反転してしまい、
   「春が落ちる」という前提そのものが再現できない。**
2. **`marginal`（効果を検出の境界に）** —— **行き過ぎて全 n で反転しなくなった。**
   そもそも**合成の帯は春161・秋177 で差が 9%** しかなく、
   **「n=161 では落ちるが n=177 では出る」という窓を作るのはほぼ不可能**だった。

3. **効果の強さの調整をやめ、`p` を `n` の関数として出した**：

| n | 有効 | 除外 | p |
|---|---|---|---|
| 177 | 60 | 0 | **100%** |
| 120 | 60 | 0 | **100%** |
| 80 | 60 | 0 | **100%** |
| 50 以下 | 0 | 60 | **年数の下限で全部除外** |

＝**効果が大きければ、日数を半分以下にしても検出できてしまう。**
**実データの秋は r=+0.63〜+0.78 と大きい**ので、
**春の日数（134/90/63）に間引いても、まず p ≈ 100% になる。**

**＝元の検定は「ほぼ必ず通る」。落ちない検定は証拠にならない。**

## もっと良い検定がある：**差を直接ブートストラップする**

私が潰したかった弱点は「**春も秋と同じ効果なのに、日数が少なくて有意にならなかっただけ**」である。
**これは「春と秋の r が違うか」を直接測れば答えられる。** 間引きは遠回りだった。

**主検定（新設）**：**Δ = r_秋 − r_春** を**年ブロック・ブートストラップ**で推定し、**95%CI を出す**。
- **年を復元抽出**し、**選ばれた年の春の日と秋の日**からそれぞれ r を計算して差を取る
  （**春と秋は同じ年から来ている**ので、**年を単位に一緒に再抽出するのが正しい**）
- **θ→γLE|Rg と θ→γH|Rg の両方**について Δ を出す
- **B = 2000 回**、**乱数の種 0**（**ここで固定する**）

## 判定規則（**実データを見る前に固定する**）

**判定できたサイトが 2 以上**のとき（対象は旗90 で判定できた US-Wkg・US-Whs・US-SRM）：

| 結果 | 結論 |
|---|---|
| **Δ_LE の CI が 0 を跨がない**（秋 > 春）サイトが過半数 | **★春と秋は本当に違う**＝**旗90 の ▲ を維持する**。「日数の差ではない」と言える |
| **Δ_LE の CI が 0 を跨ぐ**サイトが過半数 | **▲春と秋を区別できない**＝**旗90 の「Ts では説明されない」を取り下げ**、
「**帯の中では春と秋を区別できない**」と述べ直す |

**Δ_H は併記するが、判定は Δ_LE で行う**——**旗90 で春が落ちた主因は γLE 側**
（US-Wkg 春 −0.18 対 秋 +0.63）であり、**Δ を 2 つ使うと二重の検定になる**ため。
**これも今ここで決めておく。**

**元の間引き検定（p）も併せて出すが、判定には使わない**——
**ほぼ必ず通ると分かっているので、「通った」ことに意味を持たせない。**

## 予測（**低い確信で書く**）

**Δ_LE の CI は 0 を跨がない**（春と秋は本当に違う）と予測する。
**理由**：旗90 で春の点推定（−0.18／+0.30／+0.16）と秋（+0.63／+0.66／+0.78）は
**離れており、US-Wkg と US-SRM では春の CI が秋の点推定を含まない**。

**ただし確信は低い**——**私の見立ては旗88・旗89 と 2 連続で外れている**。
**外れれば旗90 を取り下げる。それが本追補を書いた目的である。**

## 事前に認めておく限界（**旗90 の他の弱点は潰れない**）

**この検定でも潰れないもの**：
- **帯に残る春が 12–22% しかない**（**晩春と晩秋を比べている**）
- **モンゴルが判定できず、独立クラスタは 2 つ**（旗89 は 3 つ）
- **Δ が 0 と違っても「春に効果が無い」とは言えない**——**「秋より小さい」までである**

**＝Δ が有意でも、旗90 は旗89 より弱いままである。** **そう書く。**

## 合成データで差の検定を確かめた（**実データ実行前**）

| 合成 | Δ_LE | 判定 |
|---|---|---|
| **秋だけ反転** | 秋 +0.69／春 −0.15／**Δ +0.85 [+0.63,+1.01]✓** | **差あり**（正しい） |
| **春秋が同じ** | 秋 +0.69／春 +0.75／**Δ −0.06 [−0.19,+0.05]·** | **差なし**（正しい） |

**両方向とも正しく区別できる。** ＝**この検定は落ちうる**＝**証拠になる。**
（**元の間引き検定は「ほぼ必ず通る」ので落ちなかった**——そこが決定的に違う。）
