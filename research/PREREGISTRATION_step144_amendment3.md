## 替えるもの（**実データの再測定より先に固定する**）

### 判定量 `t`——**「どれだけ反転しているか」を連続量にする**

    t = − sign(r_within) × r_raw

**`t > 0` が反転**（`r_raw` の符号が年内の連関と逆）。**`t` が大きいほど強く反転している。**
**`|r_raw|` がほぼ 0 のセルは `t` もほぼ 0 になる**
——**＝欠陥 #74 の後半（「ほぼ 0 の `r` の符号に意味は無い」）は、
固定の下限を足さずに、この量そのものが吸収する。**

**★固定の下限（`|r_raw| ≥ 0.10` のような）は置かない。**
**追補 B で捨てたばかりの「固定の境」を、別の量で作り直すことになるからである**（欠陥 #72 の教訓）。

### 帰無——**追補 B と同じ `year_swap`**（新しい帰無は作らない）

`yb`（γ の年平均成分）の年ラベルだけを並べ替える。**`yw` は日にくっついたまま動かない。**
並べ替え `π` ごとに

    r_between^π = Σ w·xb·yb[π] / (sx·sy^π)      sy^π = sqrt(Σ w·yb[π]² + mean(yw²))
    r_within^π  = mean(xw·yw) / (sx·sy^π)
    r_raw^π     = r_between^π + r_within^π
    t^π         = − sign(r_within^π) × r_raw^π

**`sign(r_within^π)` は `sy^π > 0` なので観測と同じ**（分母しか動かない）。
**片側 `p_flip` を取る**（反転は片側の事象である）：

    p_flip = (1 + #{ t^π ≥ t_obs − 1e-12 }) / (1 + nperm)

**`k ≥ 6` のセルにだけ当てる**（`k < 6` は「判定しない」）。**`nperm` の上限 5000 は追補 B のまま。**

### 判定規則（**符号反転ルートだけを差し替える**・他は追補 B のまま）

| 条件 | 判定 |
|---|---|
| `p < 0.05` かつ `\|r_between\| ≥ 0.15` | **骨格**（追補 B のまま・**触らない**） |
| `p < 0.05` かつ `\|r_between\| < 0.15` | **効く**（追補 B のまま・**触らない**） |
| **反転あり（`t_obs > 0`）かつ `p_flip < 0.05`** | **骨格**（★ここだけ新しい） |
| **反転あり かつ `p_flip ≥ 0.05`** | **偶然の水準と区別できない** |
| `k < 6` 年 | **判定しない**（反転していても・#75） |
| それ以外（`p ≥ 0.05`・反転なし） | **偶然の水準と区別できない** |

**`t_obs`・`p_flip`・`|r_within|`・`vshare` を必ず並べて印字する。**

## この追補で**言えないこと**（先に書く）

- **`p_flip < 0.05` は「年をまたぐ因果で符号が反転している」を意味しない。**
  **年平均どうしの結びつきが、年内の連関を偶然を超えて押し返している、以上のことは言えない。**
- **`p_flip ≥ 0.05` は「反転していない」ではない。** 反転は起きている——**偶然と区別できないだけ**である。
- **`k < 6` のセルについては、反転が本物かどうかを本追補は何も言わない**（測る道具が無い）。
- **本追補は季節差の実在も、旗88/89/91/107 の主張そのものも再判定しない。**
