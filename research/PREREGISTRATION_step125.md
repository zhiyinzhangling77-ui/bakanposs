## なぜこれをやるか（旗124 が登録した自己点検）

**Davidson, Belk & Boone 1998, GCB 4, 217–227 の本文 p.223 は、
温度と土壌水分の交絡について「統計的に非常に困難で、おそらく不可能」と結論し、
Bunnell 型乗法モデルで解が一意に定まらないことを実演している**（旗124 で全文一次確認）。

**彼らの非同定性は「温度の主効果（Q10）と水分の主効果（水分関数）」の交換可能性の話であり、
旗44 が判定に使うのは交互作用 `d` である**（`ln R = a + b·Tc + e·Tc² + c·θz + d·(Tc·θz)`）。
**パラメタの組が違うので、そのまま当たるとは言えない。だが当たらないとも言えない。**

**θz が Tc とほぼ線形に結び付くほど（|ρ|→1）、`Tc·θz` は `Tc²` に近づく**——
**`θz = ρ·Tc/SD_T + √(1−ρ²)·v` と書けば、`Tc·θz = ρ·Tc²/SD_T + √(1−ρ²)·Tc·v` であり、
第一項は `Tc²` そのものである。** **旗44 は「d が拾えること」を合成で確かめたが
（▲エイリアスのみ d→0.0000／★真の依存 d=+0.047）、それは θ–T 相関が 1 水準（既定の合成＝約 −0.5）
での話であって、`e` と `d` の識別可能性そのものは一度も測っていない。**

**旗44 が実データの節に書いた「θ-T 相関 −0.85 の JASSAL でも生存」は 1 サイトの逸話であり、
被覆率の代わりにならない**（旗124 §4）。

## 問い

**水分が温度感度に一切効かない（真の `d = 0`）合成において、
旗44 の判定手続き（`analyze` + ブロックブート 95% CI）は、θ–T 相関が強いときも
名目の被覆を保つか。それとも ★（偽陽性）を出すか。**

## 手順（先に固定する）

1. **道具は旗44 のものをそのまま import して使う**（`analyze`・`verdict`・`_boot_d`・`_design`）。
   **再実装しない。** **判定に使うのは `analyze` が返す CI だけで、しきい値も `nboot=200`・
   `block=48*7` も一つも変えない。**
2. **合成の生成器は旗44 の `_synth` と同じ形**（Lloyd–Taylor 曲率＋水分の主効果＋観測雑音 0.15）
   **に、θ–T 相関を指定する目盛りを 1 つ足しただけ**のものにする。
   - `T = 12 + 12·s + ε_T`（`s = sin(2π(doy−100)/365)`, `ε_T ~ N(0,2²)`）
   - `θ = 0.30 − A·s + ε_θ`、**`Var(θ)` を全水準で一定（= 旗44 既定の 0.00615, SD 0.0784）に保ったまま
     `A` だけを振る**——**そうしないと `d` の真値（`0.6·SD_θ`）が水準ごとに動いてしまい、
     被覆率を比べられない。**
   - **`A = −ρ·√(Var(T)·Var(θ))/(12·Var(s))`**、`σ_θ² = Var(θ) − Var(s)·A²`。
   - **時刻は暦順（30 分刻み）にする。** **★旗44 の `_synth` は `doy` を一様乱数で引いており、
     行が時間順に並んでいない＝ブロックブートが実質 iid ブートになっていた。**
     **本検証では暦順に直す**（**これは旗44 の結果を否定するものではない。
     旗44 の合成が CI のブロック構造を試せていなかったという事実の記録である**）。
3. **水準**：**ρ = −0.5 / −0.7 / −0.85 / −0.95**（旗124 が指定した 4 水準）。
4. **各水準で 2 本の腕を走らせる**：
   - **帰無腕**：真の `d = 0`（水分は「量」を変えるが「感度」は変えない）
   - **陽性対照腕（門①）**：真の `d = +0.047`（旗44 の `_synth('true')` と同じ強さ）
5. **反復 R = 100**（各腕・各水準）。`n = 20000`（30 分刻み＝約 417 日）。
6. **落ちた反復は理由ごとに数える**（旗108・欠陥 #40）：`当てはめ崩壊`（`analyze` の
   Q10 レンジ／`|d|>0.3` ガード）・`CI 不定`（ブート失敗）・`点不足`。**一つの籠に入れない。**
   **被覆率と ★率は「CI が出た反復」を分母に取り、落ちた本数を必ず併記する。**

## 判定規則（**結果を見る前に固定**）

**主判定は帰無腕の 2 つの数**：**被覆率**（CI が真値 0 を含む割合）と **★率**（`ci[0] > 0` の割合）。

| 全水準での結果 | 結論 |
|---|---|
| **すべての水準で ★率 ≤ 5% かつ 被覆率 ≥ 90%** | **○識別できている**——Davidson の非同定性は旗44 の `d` には当たらない |
| **★率 > 5% または 被覆率 < 90% が 1 水準だけ、かつ ★率 ≤ 8%** | **▲弱**——断定しない。**その水準以上を「要再点検」と書く** |
| **2 水準以上で ★率 > 5% または 被覆率 < 90%** | **▲識別が崩れる**——**旗44 の 18/36 は共線の強いサイトで水増しされている可能性がある。
その場合は「可能性がある」までしか書かない**（実サイトの相関分布が未確認のため・上記「前提」3） |

**門①（陽性対照）**：**各水準で陽性対照腕の検出率（★率）が 80% 以上あることを確かめる。**
**80% 未満の水準は、帰無腕の結果を「偽陽性が無い」の証拠に使わない**
（**検出力が無いところで偽陽性が出ないのは当たり前**＝旗95 の欠陥 #31 と同型の罠）。
**門①で落ちた水準は「判定しない」と書き、落ちたこと自体を結果として報告する。**

**補助として記録するが判定には使わない**：`corr(ê, d̂)`（反復間）・`VIF(Tc·θz)`・
`SD(d̂)`（水準間の分散拡大率）・`d̂` の中央値（偏り）。

### モンテカルロ誤差（先に書く）

**R = 100 なので、真の ★率が 2.5% でも観測値は 0〜7% の範囲に落ちうる**（二項の 95% 区間）。
**上表の 5% / 8% の線はこの誤差を織り込んで引いてある。境界の値を見てから線を動かさない。**

## 予測（**旗102 の作法：結果を見て旗44 の判定規則は変えない**）

**H1（主）**：**★率は全水準で名目内（≤5%）にとどまり、被覆率は保たれる。
共線は「偽陽性」ではなく「検出力の喪失」として現れる**——
**`Tc·θz` のうち `Tc²` に直交する成分の分散比は `(1−ρ²)/(1+2ρ²)`**（`T` が正規なら）
**＝ρ=−0.5 で 0.50、ρ=−0.95 で 0.035。つまり `SD(d̂)` は ρ=−0.95 で −0.5 の 3〜5 倍に膨らむ。
ブートストラップはこの膨張を CI 幅として拾えるので、被覆は落ちない。**

**H2（門①の副次予測）**：**その帰結として、陽性対照の検出率は ρ=−0.95 で 80% を割る**
（**＝門①で最強の共線水準が落ち、そこでは何も言えなくなる**）。

**H3（補助）**：**`corr(ê, d̂)` は |ρ| とともに単調に −1 または +1 へ近づく。**

**これは物理・統計からの予測であり、勝敗に数える：15 回目・現在 14 回中 8 勝。**

**H1 が外れる（★率が上がる）としたら最もありそうな筋**：
**Lloyd–Taylor は厳密には二次式ではないので、`e·Tc²` が曲率を吸収し切れず、
残差の非線形が `Tc·θz` に漏れる。共線が強いほど漏れ先が `d` に集中する。**
**この筋なら被覆率は落ち、`d̂` の中央値が 0 から系統的にずれる**——
**だから `d̂` の中央値も印字して、偏りと分散膨張を区別できるようにしておく。確からしさ：中。**

## 事前に認めておく限界

- **これは道具の点検であって、新しい科学的主張ではない。**
  **`MEASURED_ONLY_SPINE.md` の土俵分け・数値・スコープは、この旗では一切動かさない。**
- **合成は旗44 の生成器の形（LT ＋ 加法的な水分主効果＋対数正規雑音）に縛られている。**
  **実データがこの形から外れていれば、被覆率の結論はそのままは移らない。**
- **`e·Tc²` は Lloyd–Taylor の二次近似であり、モデルは真の生成過程を厳密には含まない。**
  **＝「真の d = 0」は「水分が感度に効かない」の意味であって、「モデルが正しく特定されている」ではない。**
- **実サイトの `corr_thT` の分布は未確認**（この周は `/mnt/hdd` が無い）。
  **★率が上がっても「実データで何サイトが該当するか」は言えない。**
  **その測定は実データのある周に回す**（`q10_confound_step44.py` の実行時に `corr_thT` を
  `runlog` で残す＝1 行の追加で済む）。
- **反復 100・水準 4 は、5% と 8% の差を確実に分ける精度を持たない。**
  **「▲弱」の欄を先に用意したのはそのためである。**
