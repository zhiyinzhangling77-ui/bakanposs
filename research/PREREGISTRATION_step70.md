# 事前登録：旗70「水マスターは**独立した別地点**でも成り立つか」

**実データを見る前に確定させ、先に commit する。**（7回目。）

## なぜこれをやるか

主張 A-3（**乾燥ステップで θ が蒸発を支配し Bowen 反転が起きる**、旗31/36）は、
旗62 で**季節を越えて成立**した（4/6）。だが旗43 の指摘——**独立地点 n=1**——は
**季節の再現では解消しない**。使った MN-Hst / MN-Nkh / MN-Kbu は
50km 単連結で**1クラスタに潰れる**からである。

旗69（事前確認）で、**手元に MN-Skt がある**と分かった：
- **独立性**：既存クラスタの最近接（MN-Nkh）から **113.4 km** ＝ **別クラスタ**。
- **実行可能性**：旗36 が要る th / Rg / gLE / gH / Ta が**5つとも既定名で一致**。

＝**独立地点を 1 → 2 にできる、手元で唯一の道**である。
（MN-Udg も独立（78.6 km）だが、**θ がどのファイルにも無い**ため
**結果を見る前に、旗69 の時点で除外を確定**した。θ が主役の検定に θ 無しは使えない。）

## 予測（実データを見る前に書く）

**H1（主要）**：MN-Skt の**夏（7–8月）**について、
**θ→γLE|Rg > 0 かつ θ→γH|Rg < 0（Bowen 反転）が成り立つ**。

**H2（副次）**：**春（4–5月）／秋（9–10月）**でも同じ符号が成り立つ（旗62 と同じ構成）。
**冬（12–2月）は凍結・積雪で θ の意味が変わるため、旗62 と同じく除外**する。

- **統計量**：Rg を偏らせた偏 Spearman 相関 r(θ,γLE|Rg) と r(θ,γH|Rg)（旗31/36 と同一）。
- **有意性**：**年ブロック・ブートストラップ**の 95%CI が 0 を跨がないこと（旗31/62 と同一）。
- **報告**：**各季節の r と CI を必ず併記**する。二値化した「回数」だけで語らない（旗59 の教訓）。
- **概念との対応**：Bowen 反転＝**逆符号の同時成立**であり、統計量はその概念そのものを測る
  （旗61 の教訓＝「統計量が対象概念を測っているか」を確認済み）。

## 判定規則（先に決める）

### 検出力の下限（旗58 の教訓＝規則に**最低検出力**を書く）

| 条件 | 扱い |
|---|---|
| 夏の日数 **< 60 日** または 健全年 **< 3 年** | **H1 を判定しない**（年ブロックブートが成立しないため） |
| 上記を満たす | H1 を判定する |

### H1 の判定

| 結果 | 結論 |
|---|---|
| θ→γLE|Rg > 0 **かつ** θ→γH|Rg < 0（**両方の CI が 0 を跨がない**） | **★独立地点で再現**：独立地点 **n を 1→2** に更新できる |
| **片方だけ**が符号どおりで CI が 0 を跨がない | **○部分再現**：どちらが再現したかを明記し、主張は「蒸発側のみ」等に縮める |
| どちらも CI が 0 を跨ぐ | **▲再現せず（検出力不足かもしれない）**：n=1 のまま。日数・年数を併記する |
| **逆符号**で CI が 0 を跨がない | **▲反証**：水マスターは**元のクラスタに固有**と明記し、主張の範囲を縮める |

### 生態系型が違った場合（**結果を見る前に決めておく**）

MN-Skt は北緯 48.35°で既存3サイトより**北**にある。**森林ステップの可能性がある**。

| MN-Skt の生態系型 | 扱い |
|---|---|
| 既存3サイトと**同じ**（半乾燥草原／ステップ） | 上表どおり＝**再現の検定** |
| **異なる**（森林・湿性草原など） | **「再現」とは呼ばない**。結果は**別生態系での検定**として報告し、
成立しても**独立地点 n=1 のまま据え置く**。不成立でも A-3 の反証にはしない |

＝**サイトの素性を見てから解釈を選ぶことをしない**ための事前約束である。

## 事前に認めておく限界

- **n=1 → 2 は依然として極小**である。★が出ても「**2地点で再現した**」以上のことは言えず、
  **一般性を確立したことにはならない**。
- MN-Skt も**同じモンゴル半乾燥ステップの気候レジーム**にある。113 km 離れていても
  **気候は共有**しうる。＝**別の気候帯での再現ではない**（そこは AmeriFlux が要る＝`DRY_SITE_EXPANSION.md`）。
- 50km 単連結は旗43 で採った**便宜的な閾値**であり、**生態学的独立性の保証ではない**。
- MN-Skt は**本研究で一度も使っていない新規サイト**である。＝**データ品質・観測期間・欠測構造が未知**で、
  「判定しない」で終わる確率が相応にある（旗56 で夜間NEEが判定不能になったのと同型の危険）。
