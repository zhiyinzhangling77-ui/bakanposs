# 事前登録：旗57「中心的主張は、まだ触っていないデータ（非森林サイト）で再現するか」

**この文書は実データを見る前に確定させ、先に commit する。**（旗55 に続く2回目の事前登録。）

## なぜこれをやるか

本研究の中心的主張（測定量だけで立つ骨格 A-1）は、**チャンバー呼吸の多日メモリ**である：
較正済み検出器で **森林 22/45**、候補を当て直しても **20/22 で説明されない**（旗53/54）。

だがこの主張は**すべて森林サイトで作られた**。メモリ解析（旗40/53/54）は一度も非森林を対象にしていない。
＝ COSORE の **草原・低木地・湿地・サバンナ・農地などは、この主張に関して完全に未使用のデータ**。
（Q10 の解析では草原を使ったが、メモリの適格判定・候補比較には一度も通していない。）

これは**保留サンプルとして使える最後の資源**であり、使う前に予測を書き留めておく必要がある。

## 予測（実データを見る前に書く）

森林で得た値を、そのまま非森林への予測として置く。

- **H1（普及率）**：非森林の**判定可能サイト**のうち、較正済み基準
  （非線形基底・R²≥0.3・ACF1≥0.64・e-fold≤7日）で短メモリと判定される割合は **0.25 より大きい**。
  （森林の実測値は 22/45 = 0.49。0.25 は「稀ではない」の下限として設定。）
- **H2（説明されなさ）**：非森林の**適格かつプラセボ有り**サイトのうち、候補
  （先行湿潤・先行水分・深層水分・非線形Birch・熱慣性）が**どれも説明しない**割合は **0.6 より大きい**。
  （森林の実測値は 20/22 = 0.91。）

## 判定規則（先に決める）

| 結果 | 結論 |
|---|---|
| H1・H2 とも満たす | **★再現**：中心的主張は森林に限らない＝**生態系タイプを越える現象**として述べてよい。 |
| 片方だけ満たす | **○部分再現**：満たした側のみ一般化し、満たさなかった側は**森林に限定**して述べる。 |
| どちらも満たさない | **▲再現せず**：中心的主張を**「森林で」と明示的に限定**する。「観測の隙間」も森林の話に絞る。 |
| 判定可能サイトが **6 未満** | **判定しない**（検出力不足）。その旨を記す。 |

## 事前に認めておく限界

- 非森林サイトは土壌温度・水分センサが疎な傾向があり、**判定可能サイト数が少なくなる可能性が高い**。
- 草原・農地は撹乱（放牧・耕耘・刈取）の影響を受け、森林と同じ機構を期待する根拠は必ずしも強くない。
  ＝ H1/H2 が満たされなくても「主張が誤り」ではなく「**適用範囲が森林**」を意味しうる。
- 降水は全 COSORE サイトで欠測のままで、Birch は θ 増加の代理検定（旗45/54 と同じ限界）。
- 閾値 0.64 は合成較正であって物理的境界ではない（旗53）。
- **森林の値（0.49／0.91）そのものが、この予測の出所**である。予測が当たっても、それは
  「同じ手続きが別の生態系でも同じ結果を出した」ことであって、機構の証明ではない。
