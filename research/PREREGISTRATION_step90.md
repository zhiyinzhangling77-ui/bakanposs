# 事前登録：旗90「**春と秋の差は、土壌温度 Ts で説明できるか**」

**実データを見る前に確定させ、先に commit する。**（11回目。）

## 問い

旗89 で、**Bowen 反転の季節依存は θ と Rg の水準に還元されなかった**——
**そのサイトにとって湿って明るい日（θ高×Rg高）に限っても、春だけ反転しない（0/6）**。
**夏は 6/6、秋は 4/6 で反転する。** **検出力では説明できない**
（反転した秋は、反転しなかった春より日数が少ない）。

**残る候補で、測定量で書けるものは土壌温度 Ts である。**
**地温は放射に遅れて動く**ので、**同じ Rg でも春の土壌は冷たく、秋の土壌は暖かい**。
＝**春と秋の差は「地温の差」かもしれない。**

**`Ts` を選ぶ理由**：**測定量であり、分割派生量ではない**（旗32/35 の派生量問題が無い）。
GPP や LAI で「フェノロジー」を測る手もあるが、**GPP は分割の産物**であり、
**この研究が一貫して避けてきた量**である。**まず測定量で試す。**

## **この検定は「共通の土俵が在るか」に懸かっている**（先に書いておく）

**春が冷たく秋が暖かいなら、そもそも比べられる日が無いかもしれない。**
＝**春と秋の Ts 分布が重ならなければ、どんな層別でも答えは出ない**（共通支持の欠如）。

**だから、検定の前に重なりを測り、足りなければ「判定できない」で終える。**
**これは失敗ではなく、「春と秋は地温で分離しており、この設計では答えられない」という結果である。**
**そう先に決めておく**——**重なりを見てから基準を決めれば、いくらでも都合よくできる。**

## 手順（**先に固定する**）

1. **旗89 と同じ層に入る**：θ と Rg を**サイトごとの中央値**（**全月プール**）で切り、
   **θ高×Rg高 のセルだけ**を使う。**しきい値は旗89 と同一**——**作り直さない**。
2. そのセルの中で、**春（3–5月）の Ts 分布と秋（9–11月）の Ts 分布**を出す。
3. **重なり帯**を **[両者の 10 パーセンタイルの大きい方, 両者の 90 パーセンタイルの小さい方]** と定める。
   **10/90 を使うのは外れ値で帯が広がるのを防ぐため。数値は今ここで固定する。**
4. **帯の中の日だけ**を残し、**春と秋を別々に**検定する
   （統計量は旗31/36/89 と同一：偏 Spearman ＋年ブロック・ブートストラップ 95%CI）。
5. **帯に残った日数・年数・Ts の帯幅・春秋それぞれの残存率を必ず出す。**

## 判定規則（先に決める）

### 共通支持の下限（**ここが今回の要**）
| 条件 | 扱い |
|---|---|
| 帯の中の**春が 60 日未満**または**春の年数が 3 未満** | **そのサイトは判定しない** |
| 帯の中の**秋が 60 日未満**または**秋の年数が 3 未満** | **そのサイトは判定しない** |
| 帯幅が **0 以下**（分布が重ならない） | **そのサイトは判定しない**（＝**地温で完全に分離している**） |

### 判定（**判定できたサイトが 3 以上**のとき）
| 結果 | 結論 |
|---|---|
| **帯の中で春も秋も反転**するサイトが多数 | **★Ts で説明された**：春の不成立は**地温が低いこと**による。A-3 を「**θ が高く、かつ土壌が暖かいとき Bowen 反転が起きる**」と書き換える |
| **帯の中でも秋は反転・春は反転しない**サイトが多数 | **▲Ts でも説明されない**：**水・エネルギー・熱のどれでもない要因**（フェノロジー等）が残る。**そう確定して記録し、測定量での説明は打ち切る** |
| **帯の中では秋も反転しなくなる**サイトが多数 | **○判定保留**：**帯に絞ったことで検出力が落ちただけ**の可能性が高い。**春について何も言えない**と記す |
| 判定できたサイトが **3 未満** | **判定しない**。**重なりが無かった**のか**日数が足りなかった**のかを**必ず区別して書く** |

### 事前に決めておく解釈上の注意
- **これは A-3 を広げる検定ではない。** 旗89 で残った季節依存を**測定量で説明できるか**の検定であり、
  **説明できなければ A-3 の記述は旗88/89 のまま変わらない。**
- **帯に絞れば n は必ず減り、相関は減衰する**（旗89 と同じ）。
  **判定は符号と CI のみ。帯の内外で r の大きさを比べない。**
- **「春も秋も反転しなくなった」を「Ts で説明された」と読んではいけない。**
  上の表で**別の行に分けてある**のはそのためである。
- **Ts の深度は不明**（旗33/80：`TS_F_MDS_1` は最浅の慣例に従っただけ）。
  **サイト間で同じ深さを比べている保証はない。**

## 予測（**低い確信で書く。理由も書く**）

**H1**：帯の中では**春も秋も反転する**（＝Ts で説明される）。

**ただし、この予測に高い確信は置かない。**
**私の機構の見立ては旗88・旗89 と 2 連続で外れている**
（「最も乾く春で最も強いはず」→外れ／「反転にはエネルギーも要る」→外れ）。
**旗89 で自分に課したとおり、機構の見立てには低い重みを置く。**
**本検定の価値は、H1 が当たることではなく、どちらに転んでも次の一手が決まることにある**：
- 当たれば → **A-3 の記述が「θ が高く土壌が暖かいとき」まで精密になる**
- 外れれば → **測定量での説明は打ち切り**、**フェノロジー（派生量を使わざるを得ない）か
  新規観測に進むしかない**と確定する

## 旗89 の教訓を織り込む（**同じ誤読を繰り返さない**）

旗89 では、**層別変数 θ が季節と周期を共有していたため、2×2 だけでは
「θ が効いている」と「季節が効いている」を分けられなかった**（欠陥26）。
**Ts は θ よりさらに季節と強く結びついている**——**だから今回は最初から
「春と秋を、Ts を揃えたうえで別々に検定する」形にしてある**。
**セルの中を季節で割るのではなく、季節ごとに帯の中で検定する**のが本設計であり、
**旗89 の誤読は構造的に起こり得ない。**

## 事前に認めておく限界

- **独立クラスタは 3 つ**（モンゴル1・Walnut Gulch・Santa Rita）＝**6 サイト≠6 反復**。
- **帯に絞ると n が落ちる**。**「判定できない」で終わる確率は相応にある。**
- **Ts の深度が不明**（上記）。
- **Ts を揃えても、Ts と一緒に動く他の量（フェノロジー・根の活性・大気の乾燥度）は揃わない。**
  ＝**「Ts で説明された」と出ても、「Ts が原因」とは言えない**——
  **「Ts を揃えると差が消える」までしか言わない。** **そう書く。**
- **合成データで道具を検証してから実データに触れる**（旗89 でこれが効いた）。
  **「Ts で説明される系列」と「Ts では説明されない系列」を作り、区別できるか確かめる。**
