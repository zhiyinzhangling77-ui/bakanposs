# 事前登録：旗96「**春に Bowen 反転が起きないのは、飽差（VPD）が高いからか**」

**実データを見る前に確定させ、先に commit する。**（15回目。）

## なぜ今これをやるのか——**打ち切りの宣言が早かったから**

旗95 で「**θ・Rg・Ts・GCC の四つを試して説明できず、観測データの層別による説明は打ち切る**」
と書いた。**早すぎた。** コードを確認すると **`VPD` は旗36・89・90・95 のどこにも現れない**
＝**一度も層別に使っていない。**

**しかも VPD は、Bowen 比にとって最も直接的な量である**——
**気孔を閉じさせるのは飽差**であり、**顕熱と潜熱の配分を直接動かす**。
**北米南西部の春は高 VPD、モンスーン後の秋は低 VPD** で、
**Rg（放射）や Ts（地温）とは別の軸で春と秋を分ける。**

**新規観測の話をする前に、残った測定量を使い切る。**

## 仮説

**H1**：**θ高×Rg高 の中で VPD を揃えると、春と秋の差が消える**
（＝**帯の中では春も秋も反転する**）。

**機構の見立て**：**春は高 VPD → 気孔が閉じる → 土壌水が増えても蒸散が応答できない
→ 顕熱への振り替えが起きない。** **秋はモンスーン後で VPD が下がり、気孔が開く。**

**確信は低い。** **事前予測は 4 回中 1 勝**（旗88 外れ・旗89 外れ・**旗91 当たり**・旗95 外れ）。
**旗89 で自分に課したとおり、機構の見立てには低い重みを置く。**

## 手順（先に固定する）

1. **場所は旗89/90/95 と同一**：θ・Rg のしきい値は**サイトごとの中央値・全月プール**、
   **θ高×Rg高 のセル**。**春＝3–5月／秋＝9–11月**。**作り直さない。**
2. **VPD の重なり帯**：春と秋の VPD 分布の **10/90 パーセンタイル**の重なり（**旗90 と同一の作り方**）。
3. **帯の中で、春と秋を別々に検定**——統計量は旗31/36/89/90/91/95 と同一
   （偏 Spearman ＋**年ブロック・ブートストラップ 95%CI**）。
4. **必ず併記する**：帯の中の**日数・年数**、**春秋それぞれの VPD・Rg・Ts・θ の中央値**。

## **旗95 の教訓を、今度は規則にする**

旗95 では**秋（対照）を「参考」としか位置づけず**、**US-Wkg で対照ごと落ちたのに
規則が発火してしまった**（設計の欠陥31）。**今回は門にする。**

**門①（対照）**：**帯の中で秋が反転しなければ、そのサイトは判定しない。**
**「春が反転しない」ことに意味を持たせるのは、同じ帯で秋が反転するときだけである。**

## **VPD が Rg の言い換えでないことを、先に確かめる**

**VPD は `es(Ta)·(1−RH/100)` であり、`Ta` は `Rg` と強く相関する**（旗32 が
「VPD は独立変数として綺麗でない」と名指しした量）。
＝**VPD の帯が、実は Rg の帯を作り直しているだけ**かもしれない。

**門②（分離可能性）**：**θ高×Rg高 のセルの中で `Spearman r(VPD, Rg) > 0.7` なら、
そのサイトは判定しない**（**VPD と Rg を分離できない**）。
**閾値 0.7 は恣意的だが、いまここで固定する。**

**あわせて**：**帯の中の Rg 中央値を春秋で併記**し、**大きく違えば「Rg が揃っていない」と明記する**
（**門にはしないが、読み方を弱める**）。

## 判定規則（先に決める）

### 下限（旗58/70/82/88–91/95 と同じ）
| 条件 | 扱い |
|---|---|
| 帯の中の**春または秋が 60 日未満**、または**年数 3 未満** | **そのサイトは判定しない** |
| **帯幅が 0 以下** | **そのサイトは判定しない**＝**春と秋は VPD で完全に分離している** |
| **門①**：帯の中で**秋が反転しない** | **そのサイトは判定しない**（対照が働いていない） |
| **門②**：セル内で **r(VPD,Rg) > 0.7** | **そのサイトは判定しない**（VPD と Rg を分離できない） |

### 判定（**門を通ったサイトが 2 以上**のとき）
| 結果 | 結論 |
|---|---|
| **帯の中で春も反転する**が過半数 | **★VPD で説明された**：A-3 を「**θ が高く、かつ飽差が低いとき Bowen 反転が起きる**」と書き換える。**ただし「VPD が原因」とは言わない**——**VPD を揃えると差が消える**まで |
| **帯の中でも春は反転しない**が過半数 | **▲VPD でも説明されない**：**測定量（θ・Rg・Ts・GCC・VPD）を使い切ったと確定**し、**新規観測へ渡す** |
| 門を通ったサイトが **2 未満** | **判定しない**。**どの門で落ちたかをサイトごとに書く** |

### 事前に決めておく解釈上の注意
- **「VPD で説明された」と出ても、A-3 の主張は広がらない。** 季節依存の説明が付くだけである。
- **VPD は Ta と RH の決定的な関数**＝**層別に使うだけなら許容するが、そう明記して読む。**
  **「VPD が独立な駆動である」とは書かない。**
- **帯に絞れば n は減り、相関は減衰する**（旗89–91/95 と同じ）。
  **判定は符号と CI のみ。帯の内外で r の大きさを比べない。**

## 対象サイト

**主**：**US-Wkg・US-Whs・US-SRM**（旗88–91/95 と同じ）。
**併せて走らせる**：**MN-Hst・MN-Nkh・MN-Kbu**——**旗90 では 1 件も判定できなかった**ので
**期待しない**が、**同じ実行に並べる**（**検出器が壊れていないことの確認**にもなる＝旗70/82 の作法）。

## 合成データで先に検証する（旗89・90・91・93・95 で 5 度効いた作法）

**実データに触れる前に、四つを作って区別できるか確かめる**：
- **`vpd`**：**VPD が高い日は反転しない**（＝VPD で説明される）→ **帯の中では春も反転すべき**
- **`season`**：**秋だけ**反転 → **帯の中でも春は反転しないべき**
- **`wet`**：**θ で反転**し VPD は θ と絡む → **帯が潰れるか、春も秋も反転すべき**
- **`collinear`**：**VPD をほぼ Rg の関数にする** → **門②が発火すべき**

**`collinear` で門②が働かなければ、Rg の言い換えを見逃す＝実データに進まない。**

## 事前に認めておく限界

- **独立クラスタは 2 つ**（Walnut Gulch・Santa Rita）。**3 サイト≠3 反復。**
- **VPD は派生に近い**（上記）。**Ta・RH の測定誤差がそのまま入る。**
- **帯に絞ると検出力が落ちる**——**旗95 では対照まで落ちた**。**今回は門で拾う。**
- **説明が付いても機構は確定しない**（旗71 以来）。**「いつ出るか」を精密にするだけ。**
