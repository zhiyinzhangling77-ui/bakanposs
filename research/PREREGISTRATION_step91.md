# 事前登録：旗91「**旗90 の ▲ は、日数の差を見ていただけではないか**」

**実データを見る前に確定させ、先に commit する。**（12回目。）

## これは新しい主張を作る検定ではない——**自分の結論を自分で試す検定**である

旗90 は「**帯の中でも秋は反転・春は反転しない → Ts でも説明されない**」と結論した。
**その直後に、私は自分でこの結論の弱点を 4 つ挙げた**。うち**最大のもの**：

| | 帯の中の春 | 帯の中の秋 |
|---|---|---|
| US-Wkg | 134 | **185** |
| US-Whs | 90 | **123** |
| US-SRM | 63 | **74** |

**3 サイトとも秋の方が日数が多い。** さらに**春の CI は秋の点推定を含むほど広い**
（US-Wkg −0.18 [−0.42,+0.38] に対し秋 +0.63）。
＝**「春も秋と同じなのに、日数が少なくて有意にならなかっただけ」というデータとも矛盾しない。**

**旗89 では逆だった**——**反転した秋の方が日数が少なかった**ので、検出力では説明できなかった。
**旗90 にはその守りが無い。** **だから直接試す。**

## やること（**一つだけ**）

**秋の日を、春と同じ日数まで無作為に間引いて、それでも反転するかを繰り返し見る。**

## 手順（先に固定する）

1. **旗90 と同じ場所に入る**：θ・Rg のしきい値は**旗89 と同一**、
   帯は**旗90 と同一**（春秋の Ts の 10/90 パーセンタイルの重なり）。**作り直さない。**
2. 帯の中の **春の日数 n_sp** と **秋の日数 n_au** を取る。**n_au > n_sp のサイトだけ**を対象にする
   （**そうでなければ弱点が存在しないので、試す必要が無い**）。
3. **秋から n_sp 日を無作為抽出**（復元なし）し、**旗90 と同一の検定**
   （偏 Spearman ＋年ブロック・ブートストラップ 95%CI）で**反転するかを判定**する。
4. **これを B = 200 回**繰り返す。**乱数の種は 0 に固定する。**
5. **200 回のうち反転した割合 p** を出す。**春の側は間引かない**（既に最小なので）。
6. **年数が 3 未満になった抽出は数えない**（旗58 以来の下限を維持）。
   **数えなかった回数も報告する。**

## 判定規則（**先に決める。閾値は今ここで固定する**）

| 結果 | 結論 |
|---|---|
| **p ≥ 0.80**（サイトの過半数で） | **★旗90 の ▲ は日数差では説明できない**＝**旗90 の結論を維持し、強める** |
| **p < 0.50**（サイトの過半数で） | **▲旗90 は検出力の差を見ていた**＝**旗90 の「Ts では説明されない」を取り下げる**。
「**帯の中では春と秋を区別できない**」と述べ直す |
| **0.50 ≤ p < 0.80** | **○どちらとも言えない**：**春の不成立には検出力の差が相応に効いている**と明記し、
旗90 の ▲ を**「弱い証拠」と格下げ**して残す |
| 対象サイトが **2 未満** | **判定しない** |

**「取り下げる」を規則にはっきり書いておく**——**自分に不利な結果が出る道を、先に用意する。**

## 予測（**低い確信で書く**）

**p は高い（0.80 以上）** と予測する。**理由**：秋の r は +0.63〜+0.78 と大きく、
**春の点推定（−0.18〜+0.30）とは重ならない大きさ**なので、
**日数を 3 割減らした程度では消えないのではないか。**

**ただし確信は低い。** **私の見立ては旗88・旗89 と 2 連続で外れている**（旗89 で自分に課した通り、
機構・大きさの見立てには低い重みを置く）。**外れれば、それは旗90 を取り下げる根拠になる。**

## 事前に認めておく限界

- **これは旗90 の弱点①だけを潰す。** 残る弱点は**潰れない**：
  **②春の CI がそもそも広い**（間引きでは変わらない）、
  **③帯に残る春が 12–22% しかない**、
  **④モンゴルが判定できず独立クラスタが 2 つ**。
  ＝**p が高く出ても、旗90 は旗89 より弱いままである。** **そう書く。**
- **無作為抽出は年の構造を壊す**（同じ年から偏って抜けうる）。
  **年ブロック・ブートストラップは抽出後の標本に対して掛ける**ので、
  **抽出で年数が減れば CI は広がる**——**その向きは保守的**（反転しにくくなる）である。
- **p は「反転が有意になる確率」であって、効果の大きさではない。**
  **p が高いことは「秋の効果が春より大きい」ことを直接示さない。**

## 合成データで先に検証する（旗89/90 と同じ作法）

**二つ作り、道具が区別できるかを確かめてから実データに触れる**：
- **`real_diff`**：**秋だけ本当に反転する**系列 → **間引いても p は高いはず**
- **`power_only`**：**春も秋も同じ強さで反転するが、春の日数だけ少ない**系列
  → **秋を春と同じ日数に間引けば p は下がるはず**

**`power_only` で p が下がらなければ、この道具は弱点を検出できない**＝**実データに進まない。**
