## 欠陥 #71：**`d = r_yr − r_raw` は「年の対比の寄与」ではない**

**`d` には二つの別物が混ざっている**：

1. **年をまたぐ共分散の除去**（＝測りたかったもの）
2. **分母の再正規化**——**年成分を除くと `θ` と `γ` の分散がどちらも減る**ので、
   **年の対比が偶然 0 でも `|r|` は必ず大きくなる**。

**2 は年成分の分散比が大きいほど強い。** G3（年成分の分散比が大）で `d` が −0.2 台に振れたのはこれである。
**＝`d` が大きいことは、年の対比が混ざっている証拠にならない。**

**旗143 の `ES-FcO` の読み（`−0.224 → −0.039`）は、この点で不正確だった**——
**ただし向きは逆**である。再正規化は `|r_yr|` を**大きくする**方向に働くのに、
**実際は小さくなった**。**＝あの地点で年の対比が効いていたという結論は保たれる**
（**弱まるのではなく、むしろ下限側の見積りになる**）。**旗143 の記述は書き換えず、本追補で補う。**

## 替えるもの（**実データを見る前に固定する**）

**主判定量を、恒等式による分解の `r_between` にする**：

```
r_raw = r_between + r_within        （交差項は厳密に消える＝実装 `decompose`）
```

`r_between` は **`r_raw` と同じ分母で測った、年をまたぐ対比の寄与そのもの**である。
**再正規化の影響を受けない。** **`d` と `r_yr` は引き続き印字するが、判定には使わない。**

### 判定規則（段階は前と同じ数値を使う）

セルごとに **`|r_between|`** を見る：

- **< 0.05** → **無視できる**
- **0.05 以上 0.15 未満** → **効いている（併記が要る）**
- **0.15 以上**、または **`sign(r_within) ≠ sign(r_raw)`** → **骨格に触る**

集計規則・結論の書き方は**本体 `PREREGISTRATION_step144.md` のまま**（1／2／3 の三分岐）。
**本周では判定を差し替えない**（穴 #69）。

### 門①の合格条件（**替えたので、較正からやり直す**）

| 門 | 作り | **合格条件** |
|---|---|---|
| **G1'** `within_only`(20年) | 年内にだけ真の連関・年平均は独立・年分散小 | **\|r_between\| 中央 < 0.03** かつ **r_within 中央 < −0.15** |
| **G2'** `between_only`(3年・20年) | 年内 0・年平均どうしにだけ真の関係 | **両方で r_between 中央 ≤ −0.15 かつ \|r_within\| 中央 < 0.05** |
| **G3'** `no_between_signal`(3年・20年) | 年内に真の連関・年平均は独立（**偶然の対比だけ**） | **\|r_between\| 中央が両方 < 0.05** かつ **SD 比 `SD(3年)/SD(20年)` が 1.8〜3.5** かつ **SD(20年) < 0.05** |

**G3' の SD 比の帯を先に導出しておく**（穴 #70：**向きだけでなく大きさを言う**）。
**年平均どうしの偶然の相関は年数 `k` の平方根で薄まる**ので、比の期待値は
**`sqrt(20/3) = 2.58`**。**帯を 1.8〜3.5 に取る**（±0.8 ほどの余裕）。
**比が 1 に近ければ「年数が多いから安全」という読みが崩れる。
比が 3.5 を超えれば、薄まり方が平方根より速く、実装を疑う。**

**3 本とも合格しなければ実データに進まない。**
