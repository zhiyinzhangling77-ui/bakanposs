# 事前登録：旗62「水マスターは夏以外の季節でも成り立つか」

**実データを見る前に確定させ、先に commit する。**（6回目。）

## これは久しぶりに「本物の確認的検定」ができる

本研究のタワー側解析は**すべて 7–8 月**で行ってきた（R&K 由来の慣習）。
＝**春・秋・冬のデータは、この主張に関して一度も使っていない**。
COSORE は使い切ったが、**JapanFlux の非夏季は未使用サンプルとして残っている**。

対象の主張は A-3（測定量だけで立つ骨格の一つ）：
**乾燥ステップで θ が蒸発を支配し、Bowen 反転が起きる**（θ→γLE>0 かつ θ→γH<0、旗31/36）。
夏で得た結論を、**未使用の季節に当てて確認する**。

## 予測（実データを見る前に書く）

**H1（符号の再現）**：モンゴル半乾燥ステップ 3 サイト（MN-Hst / MN-Nkh / MN-Kbu）について、
**夏以外の各季節でも θ→γLE|Rg > 0 かつ θ→γH|Rg < 0（Bowen 反転）が成り立つ**。
- 判定に使う季節：**春（4–5月）／秋（9–10月）**。**冬（12–2月）は凍結・積雪で θ の意味が変わるため除外**する
  （事前に決めておく。結果を見てから外すことはしない）。
- **統計量**：各サイト・各季節で、Rg を偏らせた偏相関 r(θ,γLE|Rg) と r(θ,γH|Rg)（旗31/36 と同じ）。
- **有意性**：**年ブロック・ブートストラップ**の 95%CI が 0 を跨がないこと（旗31 と同じ扱い）。
- **集計**：`サイト×季節` の全組（3サイト×2季節＝最大6組）のうち、
  **Bowen 反転（γLE 正かつ γH 負、両方ともCIが0を跨がない）が成立する割合**。

## 判定規則（先に決める）

| 結果 | 結論 |
|---|---|
| 成立が **6組中4以上** | **★季節を越えて成立**：水マスターは夏の現象ではない。主張から「夏の」という限定を外せる。 |
| 成立が **6組中2〜3** | **○部分的**：成立した季節のみ加えて述べ、他は夏に限定する。 |
| 成立が **6組中1以下** | **▲夏に限定**：水マスターは**夏の現象**と明記する。 |
| 判定可能な組が **4 未満**（データ不足） | **判定しない**。その旨を記す。 |

**注意（旗58/61 の教訓を織り込む）**：
- 統計量は**符号と CI**であり、二値化した「回数」だけで判断しない——**各組の効果量と CI を必ず併記**する。
- 「判定可能な組が4未満なら判定しない」という**最低検出力を規則に書き込む**（旗58 の反省）。
- 統計量が**対象概念（Bowen 反転＝逆符号の同時成立）を測っている**ことを確認済み（旗61 の反省）。

## 事前に認めておく限界

- **同じ3サイト**であり、旗43 の指摘（独立地点 n=1）は解消しない。
  ＝季節で再現しても「**別の季節でも同じ1地点で成り立つ**」以上のことは言えない。
  独立地点を増やすには別データが要る（`DRY_SITE_EXPANSION.md`）。
- 非夏季は**フラックスが小さく欠測も多い**可能性が高く、「判定しない」で終わる確率は相応にある
  （旗56 で夜間NEEが判定不能になったのと同型の危険）。
- 春・秋は**フェノロジーの遷移期**で、夏とは駆動の構造そのものが違いうる。
  ＝成立しなくても「夏の結論が誤り」ではなく「**季節依存**」を意味しうる。
