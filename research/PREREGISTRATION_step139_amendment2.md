## 追補 D-1：**門① G4 が落ちた**——**`diff_boot` の CI は、この地点ではそもそも季節を見ていない**

**G4（偽の季節）は事前登録が実データの前に宣言した 4 本のうちの 1 本である**：

> **季節ラベルを日付から切り離して年内で無作為に付け替えた偽データで Δ を出し、CI が 0 を跨ぐこと。
> 跨がなければ、Δ は季節ではなく日数の非対称を拾っている。**

**合否のしきい値（0.90）は、G4 を一度も走らせる前に道具の docstring に固定した**
（`phase_asymmetry_step139.py` の冒頭・旗139a の帰無で断定が 6% 出たので 10% を許容幅にした）。

**結果：200 本の偽の季節のうち、Δ(θ→γH) の CI が 0 を跨いだのは 159 本＝0.795。**
**＝季節の中身を消しても、5 本に 1 本は「季節差がある」と言ってしまう。**

**これは旗139a の欠陥 #66（年ブロックが 3 つだと `diff_boot` の CI が壊れる）が、
合成ではなく実データの上で出たものである。** **合成の被覆 0.46〜0.82 と整合する。**

**帰結（規則どおり）**：**門①が 1 本落ちた以上、事前登録の判定表を `ES-FcO` の実データに当てて
★／▲を読むことはできない**（旗96 で MN-Hst を門①で落としたのと同じ扱い）。
**判定表の「CI が 0 を跨がない」という条件が、この標本では意味を持たないからである。**

## 追補 D-2：**有意の決め方を、置換検定に差し替える**（**判定表の形は変えない**）

**壊れているのは CI であって、統計量（Δ̂ = r_SON − r_MAM）ではない。**
**そこで「有意」の判定だけを、較正できる参照分布に差し替える。**

| | **元の規則（step139 本体）** | **差し替え後（本追補）** |
|---|---|---|
| 主判定の統計量 | **Δ̂ = r_SON − r_MAM（θ→γH）** | **同じ（変えない）** |
| Δ の有意 | `diff_boot` の 95%CI が 0 を跨がない | **季節ラベルの置換 2000 本の両側 p < 0.05** |
| 単季の「反転あり」 | `_boot_ci` の 95%CI が 0 を跨がず r<0 | **θ の年内 7 日ブロック巡回シフト 2000 本の片側 p < 0.05 かつ r<0** |
| 判定表の 4 行 | ★／▲／判定しない／○弱い証拠 | **一字も変えない** |
| 下限 | 各季節 60 日・3 暦年 | **変えない** |
| 予測 H1 | ▲（低い確信） | **変えない**（**通算 16 回中 9 勝の続きとして数える**） |

**置換の作り方（先に固定する）**

1. **Δ の帰無**：**年ごとに MAM+SON の日をプールし、季節の枚数を保ったまま札を振り直す**
   （**G4 と同じ作り方**）。**日数の非対称（春 175・秋 131）はそのまま残り、季節の中身だけが消える。**
   **2000 本。両側 p = (1 + #{|Δ*| ≥ |Δ̂|}) / (2001)。**
2. **単季の帰無**：**その季節の中で、θ の系列を年ごとに 7 日ブロックの巡回シフトで回す**
   （`gH`・`Rg` の行は動かさない）。**巡回シフトは θ の自己相関を保存する**——
   **日次を素朴に並べ替えると自己相関が消えて偽陽性が増える**（旗126 が残した穴と同じ問題）。
   **2000 本。片側 p = (1 + #{r* ≤ r̂}) / (2001)。**
3. **どちらも `diff_boot` を呼ばない**（点推定だけなので速い）。

## 追補 D-3：**使う前に較正する**（**これを通らなければ実データに当てない**）

**置換検定そのものを、旗139a の合成 3 種に当てて較正する。**
**合否のしきい値をここで固定する（実行前）**：

| 合成 | 要求 |
|---|---|
| `none`（反転が無い世界） | **Δ の p < 0.05 が出る割合 ≤ 0.07**（名目 0.05・200 replicate の揺れを見込む） |
| `phase_driven` | **★の枝に到達する割合 ≥ 0.80** |
| `calendar_driven` | **▲の枝に到達する割合 ≥ 0.80** |

**`none` の偽陽性が 0.07 を超えたら、置換検定も使わない**——
**そのときは `ES-FcO` について「この標本では判定できない」で閉じ、量は記述としてのみ残す。**
**判定表を三度目に作り替えることはしない。**

## 追補 D-4：**門① G1 の月が食い違っていた**（**事前登録の見落とし・記録のみ**）

**事前登録の G1 は「同じ実装を US-SRM の秋に当てて旗88 の値（+0.81 / −0.56）を再現すること」と書いた。**
**だが旗88 の「秋」は 9–10 月であり、本検定の SON は 9–11 月である。月が違う。**

**合否は旗88 と同じ 9–10 月で取った**（**そう決めてから走らせた**）：
**θ→γLE = +0.806（旗88 +0.81）・θ→γH = −0.560（旗88 −0.56）＝○合格。**
**参考に印字した SON（9–11 月）は +0.722 / −0.440 で、反転は残るが弱い。**

**＝A-3 側の「秋」と本検定の「SON」は同じ月ではない。**
**この食い違いは判定表を動かさないが、`ES-FcO` の Δ を A-3 の Δ と並べるときには効く。**
**限界として書き足す**（`PREREGISTRATION_step139.md` の「事前に認めておく限界」に一つ足す扱い）。

**G1 のもう半分（旗106 の `遠い` 層：+0.61 / −0.39）は本周では走らせていない。**
**理由：旗106 の値は `θ高×Rg高` セルの中の量であり、step139 は事実③のためセルで切らない設計だから、
同じ実装では出せない。** **＝G1 は旗88 側だけで取った。合格の根拠は旗88 の 2 値である。**
