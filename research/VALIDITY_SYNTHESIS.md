# 妥当性検証の統合記録（旗29〜35）— 何が言えて何が言えないか

「豊かな因果構造は、貧しい・**派生を含む**観測にどう写り、どこが写らないか」を主題に、
主要な発見を **派生量・統計・品質・因果リンクの素性** で徹底的に検証した記録。
各項目の詳細は `FLAGS_LOG.md` の該当旗、方法は各 `*_stepNN.py`、品質は `japanflux_pn/DATA_QUALITY.md`。

## 2. 確定した発見（削って残った本物）

### (A) 背骨＝放射共通駆動の冗長は普遍・本物
- O-info で **エネルギー{Rg,Ta,γH,γLE}（炭素変数ゼロ＝完全に独立測定）が冗長 9/10・平均z=+149**
  ＝炭素三角(+84)より強い。合成で「NEE=GER−GEPの代数は冗長でなく相乗へ押す」と判明済みなので、
  観測された炭素三角の冗長も本物（過小評価かも）。**炭素の定義とは無関係の本物の背骨**（旗34）。
- 因果骨格でも、独立測定間の **Rg→γH・Rg→γLE・Rg→Ta・Ta→Ts・Rg→Ts** が岩盤（旗35）。
  「GEP→NEE が普遍」は恒等式で当たり前＝因果の証拠でない。**意味ある普遍背骨は独立測定間リンクに限る**。

### (B) 呼吸系は相乗（背骨とは別層）
- 呼吸系 {Rg,Ta,θ,GER} は O-info で相乗支配（旗14）＝独立検証（旗34の単一炭素 2/10冗長・平均z=−1.7）でも再現。
- **放射駆動の物理系＝冗長／θ＋呼吸を入れた系＝相乗**、の2層構造が骨太。

### (C) 乾燥草原＝水分律速呼吸（唯一の頑健な生態系署名）
- θ→GER|Ta（温度差引後の水分の呼吸制御）が **乾燥ステップ3サイトで正・年ブロックブート＋季節制御を生存**
  （MN-Hst +0.63 / MN-Nkh +0.45 / MN-Kbu +0.36, 旗31）。森林は非有意（水が足りて水分律速でない）。
- 生態系を水傾度で並べると符号が反転（乾=＋・湿=−）＝**Wang 2025 の単峰応答**（呼吸のθ最適値）上の位置を符号がエンコード。
- 例外的整合：乾燥ステップ MN-Hst はエネルギー系も相乗（潜熱が放射から脱結合）＝水制限の別の顔。

### (D) 呼吸の未観測の遅い駆動（Tak固有の測定不良でない）
- GER 日残差の自己相関が観測プロキシ（累積Rg/Ta/フェノロジー）で落ちない＝真に未観測（旗25）。
  **閉合最良の JP-Fhk(0.85) でも最強に残存**＝母体 JP-Tak の測定不良の幻でなく、呼吸に普遍的な穴。

### (E) 正直に格下げ・撤回したもの
- **水分依存Q10（旗26/27）**：最厳QCで5/8→4/8、DT/NT分割で2/5＝分割依存。頑健なのは JP-Fhk/JP-Fjy のみ。
- **「湛水系は負」の符号反転**：韓国水田 KR-CRK が正で日本水田と逆＝水管理差（連続湛水vs中干し）。撤回。
- **森林のθ→呼吸の弱い正**：年ブロックブートで非有意化＝甘い日ブートの見かけ。撤回。

## 3. 確立した方法論（＝主張の信頼性そのもの）
- **派生量監査**（旗32）：どの関係が発見でどれが定義/循環かを各サイトで仕分ける。
- **エネルギー収支EBR**（旗29, 基準E）：site-year 丸ごとの「測れ具合」を物理で1数字に。信頼度の重み。
- **因果リンクの素性仕分け**（旗35）：骨格のリンクを額面通り読まず、端の変数の独立性で意味を分ける。
- **統計の頑健化**（旗31）：年ブロックブート（自己相関）＋季節制御。甘いCIの偽陽性を除去。
- **文献裏取り**：VPD導出(Pastorello20)、DT分割のβ(VPD)(Lasslop10)、NT=温度のみ(Reichstein05)、
  u*フィルタ(Papale06)、閉合(Stoy20/Hammerle07)、単峰応答(Wang25)。コード推定を査読文献に格上げ。

## 4. 最も深い、消えない留保
- **呼吸(GER)は特に夜間、実質モデル出力**（u*除去→穴埋め→温度モデルで分割）。だから呼吸の発見
  （相乗・水分律速・未観測駆動）は**フラックスデータ単独では真値に届かない**＝独立実測（土壌チャンバー・
  u*直接・エネルギー収支）や衛星プロキシ（SIF/SMAP）が要る。これは弱点でなく「観測を増やす」動機の具体的中身。
- θの深度・単位はサイトで不統一（順位ベース解析で結論は無傷だが、絶対値解析と生態系間の絶対比較は要注意）。
