## 問い

**A-3 の非対称——「Bowen 反転（θ が上がると顕熱が下がる）は秋には出るが春には出ない」（旗88/89/106/107）
——は、植生の季節進行が作っているのか。**

**`ES-FcO` は緑度の位相が逆である**（春に作物・夏秋は刈り跡）。**位相が逆の土地で非対称も逆になるなら、
非対称は植生に付いている。位相を逆にしても非対称が暦のまま（秋側）なら、非対称は植生に付いていない。**

**これは A-3 の再現ではない。** **A-3 が別の生態系でも起きるかを見る検定ではなく、
A-3 の季節依存の原因候補を一つ切る検定である。**

## 手順（先に固定する）

1. **データ**：`/mnt/hdd/Eddy data in Spain/Oran_Ameriflux_Cereal_ASV_CLEAN_2018_2020.csv`（30 分）。
   **`th`=`SWC_1_1_1`・`γH`=`H`・`γLE`=`LE`・`Rg`=`SW_IN`。**
2. **フィルタ（事実④のとおり・先に固定）**：**`H_QC≤3` かつ `LE_QC≤3` かつ両者が −200..800 W m-2。**
   **日次は 48 本中 24 本以上。** **落とした本数と日数を必ず印字する。**
3. **統計量**：**旗88 と同じ**——**季節ごとに `θ→γLE | Rg` と `θ→γH | Rg` の偏相関**（日次・Spearman ではなく
   旗88 と同じ Pearson・**旗88 の実装をそのまま呼ぶ**）。
   **セルで切らない**（事実③）。
4. **季節差**：**Δ = r_SON − r_MAM**、**θ→γH と θ→γLE のそれぞれ。**
   **CI は旗91 の `diff_boot`（春と秋を同じ年から一緒に再抽出する年ブロック・ブート）。**
   **年は 3 つしかない。CI は広い。それを承知で使う**（**年数を増やす手は無い**）。
5. **二値化しない**（旗59 の教訓）。**r とその CI をそのまま出す。**
6. **必ず併記する**：各季節の日数・年数・θ の中央値と四分位・Rg の中央値・r・CI・Δ・Δ の CI。

## **判定規則（先に決める）**

**A-3 側の向き（旗88/106/111 で測ってある）**：**秋に θ→γH が有意に負・春は負にならない。**
**＝A-3 側の Δ(θ→γH) は負である。**

| `ES-FcO` の結果（**主判定＝θ→γH**） | 結論 |
|---|---|
| **Δ > 0 かつ 春の r(θ→γH) の CI が 0 を跨がず負**（＝**反転が春に出る**） | **★植生起因と整合**——**位相を逆にしたら非対称も逆になった** |
| **Δ < 0 かつ 秋の r(θ→γH) の CI が 0 を跨がず負**（＝**反転が秋に出る**） | **▲植生起因ではない**——**位相を逆にしても非対称は暦のまま** |
| **どちらの季節でも r(θ→γH) の CI が 0 を跨ぐ** | **判定しない**——**この地点には反転そのものが無い**（識別に使えない） |
| **Δ の CI が 0 を跨ぐが、片方の季節で反転がある** | **○弱い証拠**として、**反転が出た季節だけを書く。Δ については判定しない** |

**θ→γLE も同じ表で併記するが、主判定は θ→γH である**（旗88/106/107 と揃える。
**A-3 の「水が蒸発を支配する」側は湿潤・乾燥を問わず出やすく、季節依存が乗るのは顕熱側だから**）。

**下限**：**各季節 60 日・3 暦年**（事実④で確認済み：春 175 日・秋 131 日・各 3 年）。
**満たさなくなった場合は判定しない。**

**★層について（GATE-26 待ちの扱いを先に決める）**
**本検定は「層なし」で走らせる。** **層なしの春秋差は、雨からの日数と交絡している**
——**旗107 は Santa Rita で、層を変えると結論が変わることを実際に示した。**
**したがって本検定の結論には、次の一文を必ず付ける**（**結果がどうであれ外さない**）：

> **これは層で揃えていない春秋の差である。旗107 が示したとおり、この差は雨からの日数で説明されうる。
> 層で揃えた判定は GATE-26（`ES-FcO` の雨）が解けてから行う。**

**GATE-26 が解けたら足すもの**（**いま先に決めておく。結果を見てから決めない**）：
**`遠い`（dryspell≥7 日）層に固定して同じ Δ を出す。** **各セル 60 日・3 年を満たさなければ判定しない。**
**そのとき、層ありの結果が層なしと食い違ったら、層ありを採る**（旗107 の作法）。

## 予測（**低い確信で書く**）

**H1＝▲（植生起因ではない）。** **`ES-FcO` の Δ(θ→γH) は負、つまり反転は秋側に出る。**

**理由**：**旗89 で「反転には θ の水準が高いことが要る」が示され、「Rg が低くても θ が高ければ反転する」も
示された**（機構候補は棄却された）。**`ES-FcO` の θ は秋（中央値 16.8）と春（18.9）で大差なく**（事実③）、
**もし θ の水準だけが効くなら春秋で似た値になる。** **一方、A-3 の 4 クラスタで秋に出て春に出ないのは、
植生ではなく大気需要や境界層の季節性かもしれない**——**その場合は地中海の圃場でも秋側に出る。**

**確信は低い。** **反対の見立ても立つ**：**刈り跡の秋は蒸発面が土だけになり、θ が上がっても
顕熱が下がりにくい（＝反転が出ない）かもしれない。** **どちらが起きるか、私は知らない。**

**この予測は当たっても外れても記録する**（通算 16 回中 9 勝の続きとして数える）。

## 合成データで先に検証する（旗100/102/104/106 の作法）

  → **Δ>0・春に反転**（★枝）。**印字して確かめる性質**：合成の緑度が春 > 秋であること。

  → **Δ<0・秋に反転**（▲枝）。**印字**：緑度と反転の有無が独立であること。
- **`none`**：**反転が無い**世界 → **両季節とも CI が 0 を跨ぐ**（判定しない枝）。
  **印字**：θ→γH の真値が 0 であること。

## 事前に認めておく限界

- **n=1 地点・3 年である。** **どの結論も 1 地点の観察であり、集計ではない**（旗81 の作法）。
  **★も▲も「植生起因である／ないと決まった」とは書かない。「1 地点で整合／不整合だった」と書く。**
- **`ES-FcO` は A-3 の 4 クラスタと IGBP が違う。** **違いは位相だけではない**——
  **耕起・作付け・品種・土壌管理が入る。** **Δ の違いを「位相のせい」と特定することはできない。**
  **この検定が切れるのは「非対称が緑度の位相と一緒に動くか」だけで、動かなかったときに
  「植生は無関係」と言えるほど強くはない。**
- **層で揃えていない**（事実⑤・GATE-26）。
- **A-3 側の位相は年ごとに割れる**（事実②：Wkg 12/22・Whs 11/18）。
  **「位相が逆」は中央値の話であり、毎年の話ではない。**
- **灌漑の有無は未確認**（旗137 の指標は 605 日対中 3 日で証拠は無い・GATE-28 で PI に照会予定）。
  **灌漑があれば θ の変動が人為になり、θ→γH の意味が変わる。**
- **QC≤3 で 30 分の 4〜5 割が落ちる**（H 28712/41327・LE 24238/41447）。
  **残った日は「よく晴れて乱流が発達した日」に偏りうる。** **旗46 の議論がそのまま効く。**
