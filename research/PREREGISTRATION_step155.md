## 1. なぜやるか（穴 #91・旗154）

**`phase_asymmetry_step139.py:770` はこう書いてある：**

```python
val = sig["h"] / n if kind == "none" else verd.get(...)
```

**＝追補 D-3 の `none`（偽陽性の水準）の合否は `θ→γH` の割合だけで決まり、`θ→γLE` の割合は
印字されるが合否に入らない。**

**旗141 のログ（`research/logs/step139_20260909_041245.txt:21`）に、その入らなかった数字が残っている：**

> **Δ が有意（p<0.05）になった割合：θ→γH 0.030（6/200）／θ→γLE 0.070**

**0.070 は閾値 0.07 のちょうど上に乗っている。** **そして旗154 の G-B（20 年規模）では 0.110 まで上がった。**
**＝`θ→γLE` の水準は両方の規模で `θ→γH` より悪く、標本を増やすと悪化する。**

**旗142 の `Δ(θ→γLE) = −0.218` は、この一度も門にかからなかった量である。**
**救い（旗154 で確認済み）：旗142 はそれを「併記」に置き主判定は `θ→γH` だった＝骨格にも
`NOVELTY_ASSESSMENT.md` にも乗っていない。訂正すべき主張は無い。**
**塞ぐべきなのは「較正が量ごとに非対称である」という作法の穴のほうである。**

## 2. 前提の確認（★旗97 の作法・**設計より先に確かめた**）

**確かめたのは「本周の較正が旗141 と同じ土俵か」の 3 点である**（**いずれも実行前にコードを読んで確認**）：

1. **合成は決定論的である**——`permcal` は `synth(kind, years=3, seed=1000+i, thin=True)` と
   `perm_result(d, nperm, seed=1000+i)` を使い、**乱数の種は `i` だけで決まる**。
   **＝同じ `reps`・同じ `nperm` で走らせ直せば、旗141 とビット単位で同じ数が出る。**
   **したがって「`reps` を 200 のままで LE を合否に入れるだけ」の実行には、新しい情報が一切ない**
   （**0.070 がもう一度出て、`≤ 0.07` を丸めの上で辛うじて満たすだけ**）。
   **本周が意味を持つには標本（replicate）を増やすしかない。**
2. **`reps=200` の Monte Carlo 誤差は無視できない**——**二項の標準誤差は `sqrt(0.07·0.93/200) = 0.018`。
   `0.070 ± 0.018` は閾値 `0.07` を挟む。** **＝旗141 の値は「通った」とも「落ちた」とも言えない位置にある。**
3. **`n_shift` は印字専用である**——`n_shift` を読んでいるのは `613`（生成）・`633`（受け渡し）・
   `1017`・`1116`（印字）の 4 箇所だけで、**`r`・`p`・`Δ` の計算経路には一切入らない**
   （**旗154 の穴 #90 の「影響は印字だけ」という判断を、本周にコードで再確認した**）。

**★これが設計を変えた点**：**2 のせいで、本周の門①には「旗141 と同じ数が再現するか」（G-D）と
「増やした標本で水準がどこに落ち着くか」（G-E）の両方が要る。片方では足りない。**

## 5. 合否の使い方——**2 つの規則を、いま分けて書く**

**本周は規則を 2 つ立てる。どちらの数も結果を見る前に固定する。**

- **規則 A（旗141 と同じ形の規則を、両方の量に当てるだけ）**：
  **`max(rate_h, rate_le) ≤ 0.07` なら `none` の門は ○。** **道具が印字する ○/× はこれである。**
- **規則 B（本周に足す・厳しい側）**：
  **`rate_le` の 95% Clopper–Pearson 上端が `0.07` 以下**であること。
  **点推定が 0.07 を下回っても上端が超えるなら「通ったことにしない＝境界」と書く。**

**なぜ B を足すか**：**2 節の 2 が示したとおり、`reps` 有限では点推定だけで水準の合否を言えない。
そして「水準が保たれている」は主張を強める側の言明だから、迷ったら通さない側に倒す**
（**旗59 以来の「半分当たりを勝ちに数え替えない」と同じ向き**）。

**★`ES-FcO` の `Δ(θ→γLE) = −0.218（p=0.0145）` を「読んでよい量」に昇格させるのは、規則 B を満たしたときだけ。**

**規則 A と B が食い違った場合（A ○・B ×）にどう書くかも、いま決めておく**：
**「`ES-FcO` の規模で `θ→γLE` の水準が 0.07 を保つとは、この標本数では示せなかった」と書く。
「保たれている」とも「壊れている」とも書かない。**

### 本周がしないこと（**先に書いておく**）
- **20 年規模（旗154 の G-B が 0.110 で落ちた側）の帰無を作り直さない。** **別の 1 単位である。**
- **A-3 の `Δ` の `p` を読まない。** **G-B は本周では通し直していない。**
- **骨格にも `NOVELTY_ASSESSMENT.md` にも足さない。**
- **`ES-FcO` の実データを走らせ直さない。** **旗142 の値をそのまま使う**（本周が変えるのは、
  その値に `p` を付けてよいかどうかの資格だけである）。
