## 問い

**「雨の直後 または 秋」という型は、湿潤な森林でも現れるか。**

**旗107 で Santa Rita に見えたこの型は、事後のパターン合わせだった。**
**今回は事前に登録する。** **四つの型を先に書き、どれに当たるかを見る。**

## 手順（先に固定する）

1. **門①-a**：**そのサイトの秋全体（層別せず）で Bowen 反転すること。**
   **反転しなければ、そのサイトは判定しない**（旗106 と同一）。
2. **測る量は二つ**：
   - **(A) 秋の中の層別**：`直後` と `遠い` のそれぞれで反転するか（旗106 と同一）
   - **(B) 層の中の季節差**：`直後` 層と `遠い` 層のそれぞれで **Δ = r_秋 − r_春**（旗107 と同一）
3. **統計量・しきい値・下限は旗106/107 と完全に同一**
   （`θ高×Rg高`・イベント 5 mm・`直後` ≤3 日・`遠い` ≥7 日・60 日・3 暦年・
   `usable` の手当て・年ブロック・ブート）。**一つも変えない。**
4. **必ず併記する**：**各群の日数・年数・θ の中央値と四分位・r とその CI・Δ とその CI。**

## **四つの型（先に登録する）**——**旗107 で事後に見つけた「または」を、事前に入れる**

**判定は (B) の Δ の組で行う**（**主判定は θ→γH**・旗106 留保②）：

| `遠い` の Δ | `直後` の Δ | 型 | 意味 |
|---|---|---|---|
| ≈0（跨ぐ） | ≈0（跨ぐ） | **`rain_only`** | **雨からの日数だけで決まる** |
| ≠0（跨がない） | ≠0（跨がない） | **`season_only`** | **雨とは無関係に季節が効く** |
| ≈0 | ≠0 | **`both`** | **雨**かつ**秋の両方が要る** |
| **≠0** | **≈0** | **`or`** | **雨の直後**または**秋**（**Santa Rita の型**） |

## 判定規則（**クラスタで書く**・旗106 の反省）

| 結果 | 結論 |
|---|---|
| **門①-a を通るクラスタが 0** | **★湿潤林では Bowen 反転が起きない**——**A-3 のスコープ（乾燥地に限る）を支持する** |
| **通ったクラスタの過半数が `or`** | **○「雨または秋」は湿潤林にも現れる**（**外挿であって再現ではない**） |
| **通ったクラスタの過半数が `or` 以外の同じ型** | **○その型が湿潤林で現れた**。**型の名前をそのまま書く** |
| **型が割れる** | **○クラスタごとに書き、まとめない** |
| 通ったクラスタが 1 のみ | **判定しない**（**n=1 では型を主張しない**） |

**「門①-a を通るクラスタが 0」も結果である**——**空振りではない。**
**A-3 が乾燥地に限るという主張は、これまで「乾燥地でしか試していない」から言えていなかった。**
**湿潤林で反転しないことを示せば、初めて「限る」と言える。**

## 予測（**低い確信で書く**）

**H1**：**門①-a を通るクラスタは 0 か 1**。
**理由**：**湿潤な森林はエネルギー制限であって水制限ではない。**
**θ が高い日に潜熱が増え顕熱が減るという関係は、水が足りている場所では出にくいはずである。**

**これは物理からの予測なので、旗102 の反省に従い、合成で向きを確かめてから確信を決める。**
**確信は低いまま書く。** **通算は 10 回中 4 勝。**

**外れ方も先に書く**：**もし湿潤林で反転が出たら、それは A-3 の枠組みそのものへの反例**である。
**「乾燥地で水がマスター」は「湿潤地では違う」を含意しているので、
湿潤林でも同じ関係が出るなら、A-3 の説明（水制限）が間違っている可能性が上がる。**

- **母集団が違う。** **どんな結果も「再現」ではない。**
- **手元の乾燥地クラスタは 2 が上限**（旗108）。**本検定はクラスタ数を増やすが、
  それは別の母集団のクラスタである。**

  **同じ層別語を使っているが、指しているものが同じとは限らない。**

  「Santa Rita で見た型が確かめられた」とは書かない**——**母集団が違うからである。**

## 追補（**実データ実行前**・合成検証で**判定規則に欠陥が見つかった**）

### 欠陥：**「CI が 0 を跨がない」だけでは、実質ゼロの差まで「差あり」になる**

**五つの合成のうち二つが期待どおりに出なかった**：
**`rain_only` → `both` と誤分類**、**`or` → `season_only` と誤分類**。

**原因は同じ一点である**——**`直後` 層の Δ が +0.039 [0.004, 0.092]** で、
**実質ゼロなのに CI が 0 を外れていた。**
**効果が大きく標本が多いと、無視できる差でも CI が 0 を外れる。**

| 合成 | `遠い` の Δ | `直後` の Δ |
|---|---|---|
| `rain_only` | +0.003 [−0.222,+0.280] | **+0.039 [+0.004,+0.092]** ← ここ |
| `or` | −0.787 [−0.945,−0.535] | **+0.039 [+0.004,+0.092]** ← ここ |
| `season_only` | −0.787 | −0.896 |
| `both` | +0.003 | −0.896 |

### **これは旗75 の教訓の 2 度目である**
**旗75**：**「プラセボより良い」だけでは勝てない。絶対的な下限が要る。**
**旗106** でも `FLOOR = 0.20`（減少率）を置いた。
**今回は同じ形を、差 Δ について踏んだ。**

> **統計的に 0 と区別できることと、意味のある大きさであることは別である。**
> **CI と絶対的な下限を、両方要求する。**

### 修正（**実データ実行前**・**下限を新たに置く**）

**「差がある」＝ CI が 0 を跨がない **かつ** |Δ| ≥ 0.15。**

**0.15 は恣意的だが、いまここで固定する。** **選び方を明記する**：
- **合成の五つがすべて期待どおりになる範囲は 0.04〜0.53** である（`rain_only` の 0.039 と
  `or`/`season_only` の 0.787 の間）。**その中央付近を取った。**
- **旗107 の実測（US-Wkg −0.10・US-Whs −0.05・US-SRM −0.38）では、
  この下限を入れても判定が一つも変わらない**ことを確かめた
  （**−0.38 だけが下限を超え、他は元から CI が 0 を跨いでいた**）。
  **＝過去の結論を書き換えるための下限ではない。**

**変えたのは判定規則である**（**しきい値や統計量ではない**）。
**実データを見る前であり、旗107 の結果に対して中立であることを確かめたうえでの変更である。**
**この二点を満たさない規則変更はしない。**
