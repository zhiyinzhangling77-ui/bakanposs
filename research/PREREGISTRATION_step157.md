## 1. なぜ書くか（旗156 が最優先に置いた宿題）

**旗156 は、20 年規模の `none`（θ→γ の真値が 0 の世界）で `Δ` の偽陽性が
`θ→γH` 0.073・`θ→γLE` 0.097 と、どちらも名目 0.05 より上に出ることを 600 本で確かめた。**
**そして「LE だけが悪い」という旗154 の読みは 600 本では成り立たないことも示した
（McNemar 両側 p = 0.1456）。** **＝緩さは LE 固有ではなく、帰無そのものが全体として緩い。**

**旗144 が、別の土俵で、これと噛み合う事実を出している**——
**偶然の年間対比 `r_between` の大きさは、年数ではなく `vshare`
（θ の分散に年成分が占める取り分）でほぼ決まる。**

**本周の問いは一つ**：
> **`none`(20 年) の `Δ` に混ざる偽陽性は、`Δ` の年間成分（`Δ_between`）が運んでいるのか。**

**機構の見立て（実行前に書く）**：
`perm_delta_p` の帰無は**年ごとに MAM+SON をプールして季節の札を振り直す**。
**年をまたぐ構造は帰無の中でも保存される**（各年の日はその年に留まる）。
**だが観測側では、MAM の日と SON の日は別の季節から来ており、
その二つの部分集合の年平均は季節周期のぶんだけ系統的に違う。**
**札を振り直すとその違いが消える。** **＝帰無の `Δ*` は年間成分のばらつきを過小に見る可能性がある。**
**過小なら `p` は小さく出る側に偏り、偽陽性が名目を超える。**
**これは見立てであって、確かめるのが本周である。** **外れうる。**

### 前提の確認で分かったこと（`logs/step157_premise_*.txt`・**判定の数ではない**）

| | 実測 | 意味 |
|---|---|---|
| **P-1** | `decompose` の `r_between + r_within` と検定の `partial_spearman` の最大差 **3.1e-17** | **分解しているのは検定と同じ量である**（旗144 の欠陥 #78 と同じ事故は起きない） |
| **P-2** | 作り直した `Δ` と旗156 の CSV の最大差 **4.4e-07**（CSV は 6 桁で保存） | **種 `7000+i` は決定論＝CSV の `sig` と本周の分解は同じ標本の上で突き合わせられる** |
| **P-3** | 1 本 **0.010 s** → 600 本で **6 秒** | **前景で走る**（旗156 の 600 s 上限の問題は本周には無い） |
| **P-4** | `vshare` 中央 **MAM 0.269・SON 0.264**（四分位 0.22–0.33・30 本） | **旗144 の表の高い側**（0.205→`\|r_bet\|` 中央 0.058・0.321→0.099）。**年成分は薄くない** |

**P-4 の補足（実行前に気づいた道具の性質）**：`decompose` の第 3 要素は **θ 側の年成分の分散比**なので、
**同じ季節なら `h` と `le` で必ず同じ値になる**。**季節ごとに 1 つの数であって、系列ごとに 2 つではない。**

## 2. 測る量（**実行前に定義を固定する**）

**標本**：旗156 が残した `logs/step156_pairs_none_20260914_200040.csv` の **600 本**
（`none`・20 年・`thin=False`・種 `7000+i`）と、
`logs/step156_pairs_calendar_driven_20260914_203704.csv` の **100 本**（門① G-L 用）。
**`sig_h`・`sig_le`・`p_h`・`p_le` は旗156 の値をそのまま使う**（**置換を回し直さない**）。

各 replicate `i` について、MAM と SON の各々で、`gH`・`gLE` の各々を
`year_contrast_step144.decompose(γ, θ, Rg, year)` にかけ、`r_between`・`r_within` を得る。**そのうえで**

- **`Δ_b` ＝ `r_between`(SON) − `r_between`(MAM)**
- **`Δ_w` ＝ `r_within`(SON) − `r_within`(MAM)**
- **恒等式 `Δ̂ = Δ_b + Δ_w`**（P-1 が最大 3.1e-17 で成り立つことを確かめた式の差）
- **★年間の取り分 `s` ＝ `|Δ_b| / (|Δ_b| + |Δ_w|)`**（0〜1・**主判定はこれに当てる**）

### なぜ `s` であって `|Δ_b|` ではないか（**交絡を実行前に潰しておく**）

**`|Δ_b|` が有意群で大きいのは当たり前でありうる**——`Δ_b` は `Δ̂` の一部なので、
`|Δ̂|` が大きい replicate では `|Δ_b|` も `|Δ_w|` も揃って大きくなる。
**それは「年間成分が偽陽性を運んでいる」ことの証拠にならない。**
**取り分 `s` は `|Δ̂|` の大きさで割り戻した量なので、この交絡を受けない。**
**`|Δ_b|` そのものは併記に落とす。**

## 4. 判定（**先に規則を書く。数を見てから変えない**）

### D-1（主判定）：`none` 600 本で、`s` は有意群のほうが大きいか

`h`・`le` の各々について、`sig=1` の群と `sig=0` の群で `s` を比べる。
**Mann-Whitney U（両側・`scipy.stats.mannwhitneyu`）**、有意水準 0.05。
**効果量は rank-biserial `r_rb = 2U/(n1 n2) − 1` で併記する**（穴 #93 の作法：差の大きさを言葉の前に置く）。

| 結果 | 書き方（**先に決める**） |
|---|---|
| **両側 p < 0.05 かつ `s` の中央値が有意群で大きい** | **「20 年規模の `none` の偽陽性は、`Δ` の年間成分が不釣り合いに運んでいる」** |
| **p ≥ 0.05** | **「この標本数では、年間成分の取り分が偽陽性と結びつくとは示せなかった」**（**「結びつかない」とは書かない**） |
| **p < 0.05 だが中央値が有意群で小さい** | **「見立てと逆向き＝偽陽性を運んでいるのは年内成分のほうである」** |

**`h` と `le` で答えが割れた場合**：**どちらも書く。合成して 1 文にしない**（旗156 の McNemar が
「差は区別できなかった」で止まっている以上、二つを一つにまとめる根拠が無い）。
**多重性**：族は `h`・`le` の 2 件。**Bonferroni なら 0.025**。**補正後の合否も必ず併記する**（穴 #83）。

### D-2（併記）：`|Δ_b|`・`|Δ_w|`・`s` の分布

有意群／非有意群それぞれの中央値と四分位を印字する。**判定はしない。**

### D-3（併記）：`Δ̂` のばらつきの分解

600 本にわたる **`Var(Δ̂) = Var(Δ_b) + Var(Δ_w) + 2Cov(Δ_b, Δ_w)`** を印字し、各項の取り分を出す。
**判定はしない**（記述である）。

### D-5（主判定の相棒）：**置換帰無は年間成分のばらつきを再現するか**

**`i` = 0..59 の 60 本**について、旗156 と同じ置換（`nperm`=2000・`seed`=`i`）を回し直し、
**置換 1 本ごとに `Δ*_b`・`Δ*_w` を分解して記録する**（計算量は P-3 の見積りの外なので、
**500 置換に落としてよい**——落とす場合はログに明記する）。そのうえで

- **`SD_null(Δ*_b)`** ＝ replicate 内で置換にわたる標準偏差。**60 本の中央値**を取る。
- **`SD_obs(Δ_b)`** ＝ **600 本にわたる** `Δ_b` の標準偏差（D-3 で出す量）。
- 同じものを `Δ_w` についても出す。

| 結果 | 書き方（**先に決める**） |
|---|---|
| **`SD_null(Δ*_b) / SD_obs(Δ_b) < 0.8` かつ `Δ_w` の比は 0.8〜1.25 に入る** | **「置換帰無は年間成分のばらつきだけを過小に見ている＝それが緩さの出どころである」** |
| **両方の比が 0.8〜1.25 に入る** | **「置換帰無は両成分を再現している＝緩さの出どころは分解の外にある」**（見立ては外れ） |
| **`Δ_w` の比も 0.8 を割る** | **「帰無は全体として狭い＝年間／年内の切り方では説明が付かない」** |
| **上のどれにも当たらない** | **「判定しない」と書き、数だけ残す** |

**0.8／1.25 は互いの逆数で、実行前に置いた**。**この境に根拠は無い**（旗144 の欠陥 #73 の教訓：
帯の中心を式で置くなら合成で確かめてから登録する。**本周は式で置いていないので、
「恣意的に置いた境である」と最初から書く**）。
