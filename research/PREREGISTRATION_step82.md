# 事前登録：旗82「水マスターは**別の気候帯**でも成り立つか」

**実データを見る前に確定させ、先に commit する。**（8回目。）

## これは `DRY_SITE_EXPANSION.md` が計画した検定そのもの

主張 A-3（**乾燥ステップで θ が蒸発を支配し Bowen 反転が起きる**、旗31/36）は、
- 旗62 で**季節を越えて成立**（4/6）したが、
- 旗70 で**同じモンゴル内 113km 先（MN-Skt）では再現しなかった**、
- 旗71 で「MN-Skt は湿っているだけ」という説明（θ 閾値仮説）も**支持されなかった**
  （水制限が現れる層がサイトごとに違った）。

＝**主張は「MN-Hst/Nkh/Kbu のクラスタで観測された現象」まで縮んでいる**。
旗79 で **US-Wkg / US-Whs / US-SRM** を登録できたので、**別の気候帯（北米半乾燥地）**で検定する。

**これは旗70 とは別の問い**である。旗70 は「**同じ気候帯の別地点**」だったが、今回は
「**別の気候帯**」——**モンゴル大陸性ステップ 対 北米南西部の半乾燥地（夏季モンスーン）**。
出れば**気候帯をまたぐ再現**であり、出なければ**A-3 はモンゴルのクラスタに固有**と確定する。

## 独立地点はいくつ増えるのか（**先に数えておく**）

旗79 の BADM 座標で計算すると：
- **US-Wkg（31.7365, −109.9419）と US-Whs（31.7438, −110.0522）は 10.45 km**
  ＝旗43 の 50km 単連結では**同一クラスタ**。
- **US-SRM（31.8214, −110.8661）は Whs から約 77 km**＝**別クラスタ**。

＝**北米で増える独立クラスタは最大 2 つ**（Walnut Gulch／Santa Rita）。
**「3サイト取ったから n が 3 増える」ではない**——旗43 で自分が名指しした擬似反復を、先に数えておく。

## 予測（実データを見る前に書く）

**H1（主要・US-Wkg）**：**半乾燥草原 US-Wkg** の**夏（7–8月）**について、
**θ→γLE|Rg > 0 かつ θ→γH|Rg < 0（Bowen 反転）が成り立つ**。
- **US-Wkg を主要にする理由**：元の主張は**草原**（モンゴル半乾燥ステップ）についてのもの。
  US-Wkg は **Kendall Grasslands ＝草原**で、**植生型が一致する唯一のサイト**である。
- **統計量**：Rg を偏らせた偏 Spearman 相関 r(θ,γLE|Rg) と r(θ,γH|Rg)（旗31/36/62/70 と同一）。
- **有意性**：**年ブロック・ブートストラップ**の 95%CI が 0 を跨がないこと（同一）。
- **報告**：各サイトの **r と CI を必ず併記**する（二値化した回数だけで語らない、旗59 の教訓）。

**H2（副次）**：**US-Whs（低木地）／US-SRM（メスキート・サバンナ）**でも同じ符号が成り立つ。
これらは**植生型が違う**ので、**成立しなくても H1 の反証にはしない**——そう先に決めておく。

## 判定規則（先に決める）

### 検出力の下限（旗58/70 と同じ）
| 条件 | 扱い |
|---|---|
| 夏の日数 **< 60 日** または 年数 **< 3 年** | **判定しない** |
| 上記を満たす | 判定する |

### H1（US-Wkg）の判定
| 結果 | 結論 |
|---|---|
| θ→γLE\|Rg > 0 **かつ** θ→γH\|Rg < 0（**両方の CI が 0 を跨がない**） | **★別の気候帯で再現**：独立クラスタが **1 → 2** になり、A-3 は初めて「反復のある主張」になる |
| **片方だけ**符号どおりで有意 | **○部分再現**：どちらが再現したかを明記し、主張を「蒸発側のみ」等に縮める |
| どちらも CI が 0 を跨ぐ | **▲再現せず**：n=1 のまま。日数・年数を併記する |
| **逆符号**で CI が 0 を跨がない | **▲反証**：**A-3 はモンゴルのクラスタに固有**と確定し、そう書く |

### 事前に決めておく解釈上の注意
- **夏季モンスーン**：北米南西部の 7–8 月は**モンスーンで最も雨が多い季節**。モンゴルも夏が雨季なので
  「**生育期かつ雨季**」という点では対応するが、**降雨の時間構造（強い対流性の雨）は違う**。
  ＝**成立しても「同じ機構」とまでは言わない**。
- **US-Whs と US-SRM が成立して US-Wkg が成立しない**場合は、
  **「草原では出ないが低木地・サバンナでは出る」**と記す。**植生型を跨いだ一般化はしない**。

## 事前に認めておく限界

- **北米で増える独立クラスタは最大 2 つ**（上に計算済み）。**3 サイト＝3 反復ではない**。
- **θ の深度が不明**（旗80）。FLUXNET 版の `SWC_F_MDS_1` は**最浅の慣例に従っただけ**で、
  **モンゴル側の深度と一致する保証はない**＝旗33 の指摘がそのまま残る。
- **FLUXNET 版はギャップフィル済み**（旗46：穴埋めは冗長を押し上げる）。
  ただし本検定は**偏相関の符号**であり、旗46 が問題にした Ω とは別の量である。
- **成立しても A-3 の「機構」は分からない**。旗71 で「θ の水準では説明できない」と分かったまま。
