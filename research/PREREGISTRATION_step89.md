# 事前登録：旗89「**Bowen 反転の季節依存は、θ と Rg の水準に還元されるか**」

**実データを見る前に確定させ、先に commit する。**（10回目。）

## 問い

旗88 で、**A-3 の半分が季節に依ることが分かった**：

| | 蒸発側 θ→γLE\|Rg > 0 | Bowen 反転（＋ θ→γH\|Rg < 0） |
|---|---|---|
| 北米 3 サイト × 春夏秋冬 | **9/9 成立** | **4/9**（秋 3・冬 1） |

＝**水が蒸発を支配することは季節に依らない。季節に依るのは「顕熱への振り替え」の方である。**

**「季節」は札であって物理量ではない。** 秋に出て春に出ないなら、
**秋と春で何が違うのか**を量で言えなければ、説明したことにならない。

**候補**：**反転が見えるには「水がある」だけでなく「使えるエネルギーもある」必要がある**のではないか。
- 秋＝モンスーン直後で**湿っており放射もまだ高い** → 3/3 反転
- 春＝**放射は高いが乾いている** → 蒸発側のみ
- 冬＝**湿ってはいるが放射が低い** → 蒸発側のみ（US-Whs を除く）

**測定された傍証**：`corr(Rg,γLE)` は**秋だけ正**（US:+0.21/+0.14/+0.15）、
**春（−0.10/−0.13/−0.14）と冬（−0.02/−0.05/−0.07）は負**。

**本検定は、この候補を「季節を使わずに」言い直せるかを確かめる。**

## 層別の切り方（**ここを先に固定するのが本文書の要点**）

**後から切り方を決めれば、いくらでも都合よく切れる**（旗75 で「プラセボより良い」だけで
勝てる規則を作ってしまった失敗と同じ型）。以下を**固定する**。

1. **層別変数は θ と Rg の 2 つ。日平均の生値**（アノマリではない——**水準**を問うているため）。
2. **しきい値はサイトごとの中央値**。**全月をプールして計算する**
   （季節ごとに計算すると**季節を層の定義に埋め込んでしまう**）。
3. **2×2 の 4 セル**：θ高×Rg高／θ高×Rg低／θ低×Rg高／θ低×Rg低。
   **三分位にしない**——層別で n が落ちるため、**検出力を優先する**。
4. **統計量は旗31/36/62/70/82/88 と同一**：各セル内で
   偏 Spearman r(θ,γLE|Rg) と r(θ,γH|Rg)、**年ブロック・ブートストラップの 95%CI**。
5. **月は全月**（1–12）。**季節はセルの中身を記述するためだけに使い、層の定義には使わない。**

### **範囲制限による減衰を、先に認めておく**
θ の水準で切ると、**セル内で θ の分散が減り、相関は必ず小さくなる**（range restriction）。
＝**この検定は保守的**であり、**「有意にならない」側に偏る**。したがって：
- **判定は符号と CI のみで行う。セル間で r の大きさを比べない。**
- **θ高×Rg高 で反転が出たなら、減衰を押し切って出たということ**＝強い証拠として扱ってよい。
- **出なかった場合、「無い」とは言えない**——**減衰と区別できない**と書く。

### **層別が効いていないときの安全弁（先に決める）**
Rg は季節と強く相関するので、**「θ高×Rg高」が秋の日ばかりになる**恐れがある。
そうなれば**季節を物理量に置き換えたのではなく、季節を言い換えただけ**である。

**各セルの季節内訳（春/夏/秋/冬の日数割合）を必ず出す。**
**あるセルで単一季節が 70% 以上を占めたら、そのセルの結果は「季節と分離できていない」と記し、
「還元された」の証拠には使わない。** ——**この閾値をいま決めておく。**

## 予測（実データを見る前に書く）

**H1（主要）**：**θ高×Rg高のセルでは、季節に依らず Bowen 反転が成立する。**
**H2（主要・対）**：**θ高×Rg低 と θ低×Rg高 では成立しない**（＝**両方が要る**）。

**H3（副次・記述のみ）**：θ高×Rg高のセルを**春だけに絞っても**反転が出る。
——**n が小さくなる公算が高い**ので、**合否には使わず、出れば強い傍証として記す**。

## 判定規則（先に決める）

### 検出力の下限（旗58/70/82/88 と同じ）
| 条件 | 扱い |
|---|---|
| セルの日数 **< 60 日** または 年数 **< 3 年** | **そのセルは判定しない** |
| セルの単一季節割合 **≥ 70%** | **そのセルは「季節と分離できていない」**＝還元の証拠に使わない |

### 判定（**北米 3 サイト＋モンゴル 3 サイト＝最大 6 サイト**で数える）
| 結果 | 結論 |
|---|---|
| **θ高×Rg高で反転が過半数（4/6 以上）成立し、かつ θ高×Rg低・θ低×Rg高では過半数が不成立** | **★季節は θ と Rg の水準に還元された**。A-3 を「**θ と Rg がともに高いとき Bowen 反転が起きる**」と書き換える |
| **θ高×Rg高 と θ高×Rg低 の両方で過半数成立**（Rg 低でも出る） | **○θ だけで決まる**。**Rg は要らない**と述べ、候補の「エネルギーも要る」を**取り下げる** |
| **θ高×Rg高 と θ低×Rg高 の両方で過半数成立**（θ 低でも出る） | **○Rg だけで決まる**。**「水マスター」という読み方を見直す**——これは A-3 に不利な結果である |
| **θ高×Rg高でも過半数が不成立**、または**季節内訳で 70% 規則に触れる** | **▲還元されない**。**季節そのものに別の要因（フェノロジー等）が在る**と記し、**季節依存を未解明のまま残す** |
| 判定できるセルが **4 サイト未満** | **判定しない**。日数・年数・季節内訳を併記して終える |

### 事前に決めておく解釈上の注意
- **これは A-3 を広げる検定ではない。** 旗88 で見つかった**季節依存を説明できるか**の検定であり、
  **説明できなければ A-3 の記述は旗88 のまま**（「蒸発は季節に依らず、反転は季節による」）で変わらない。
- **「θ と Rg がともに高い」は、モンゴルと北米で絶対値が違う**（サイトごとの中央値で切るため）。
  ＝**「同じ物理条件」ではなく「そのサイトにとって湿って明るい日」**である。**そう書く。**
- **反転が出ても機構は分からない**。旗71 で「θ の水準では説明できない」と確認済みであり、
  **本検定は「いつ出るか」を精密にするだけで、「なぜ出るか」には答えない。**

## 事前に認めておく限界

- **独立クラスタは 3 つ**（モンゴル 1・Walnut Gulch・Santa Rita）。**6 サイト＝6 反復ではない。**
- **範囲制限による減衰**（上記）。**保守的な検定である。**
- **θ の深度が不明**（旗33/80）。サイト間で同じ深さを比べている保証はない。
- **FLUXNET 版はギャップフィル済み**（旗46）。**セルごとに穴埋め率が違いうる**ので、
  **各セルの N を必ず併記する。**
- **Rg と θ は独立ではない**（雨の日は暗い）。**4 セルの日数は等しくならない**——
  **特に θ高×Rg高 と θ低×Rg低 に偏る公算がある**。**日数を必ず出す。**
