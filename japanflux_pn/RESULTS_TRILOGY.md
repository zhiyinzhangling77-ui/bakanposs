## 1. 各図の厳密な説明

### fig2b_conditioning（共通原因を差し引く）
- **縦軸の % は何の割合か**：相互情報量 I を**正規化定数 log(m)（m＝ビン数＝11）で割った値**×100。
  つまり I′ = I / log(m)（Ruddell & Kumar 2009 の規格化）。**「2変数が共有する情報を、取りうる最大
  （log m）に対する割合で表したもの」**。分散の割合ではなく、情報量の割合。
  - 青＝条件付け**前** I(X;Y)、薄青＝**放射 Rg で条件付けた後** I(X;Y|Rg)。
- **なぜ "Energy/carbon fluxes" と "Temperature–respiration" に分けたか**：**結果でそう分かれたから**。
  - 左（エネルギー・炭素フラックスどうしの結合：γH–GEP, γLE–GEP, γH–γLE, NEE–GEP）＝**Rg を差し引くと
    崩れる**→これらの見かけのつながりは**放射という共通原因の影**だった。
  - 右（温度・土壌・呼吸の結合：Ta–Ts, Ta–GER, Ts–GER, θ–GER）＝**Rg を差し引いても残る／むしろ増える**
    →放射に依らない**直接の結合**。
  - 対比（見かけ vs 本物）を見せるためのグループ分け。

### fig3_causal_skeleton（PCMCIで本当の因果の矢印）
- **PCMCI とは**：時系列の**多変量因果探索**。2段階。①各変数について「その未来を説明する候補（親）」を
  他の変数を条件に入れて絞る（PC段階）。②残った候補それぞれを、**両者の親をすべて条件に入れて**独立性
  検定（MCI段階）→ **共通原因・間接経路・自己相関を除いた"直接の因果の矢印"だけ**を残す。
  実装：tigramite の PCMCI+、ラグ tau=1〜6（0.5〜3時間）、pc_alpha=0.01、既定は線形 ParCorr
  （非線形 CMIknn も選択可）。
- **1つの変数が Rg からも別の変数からも矢印をもらう、とは**：その変数が**複数の直接原因に同時に制御
  されている**（一本鎖でなく"合流"）。例：γLE（蒸発）は **Rg←（エネルギー供給）** と **VPD←（大気の
  乾き＝蒸発の需要）** の両方が直接動かす。Ts（地温）は **Rg** と **Ta** の両方。物理的に自然。
- **GEP や NEE は Rg の影響を受けないのか？**（重要・正直に）：
  - 物理的には受ける（光合成には光が要る）。ただし**頑健な"直接の矢印" Rg→GEP は出なかった**（数年のみ）。
    理由：(a) **5日アノマリで日周期を除去**（Rg–GPP の最も強い連動は日周期）、(b) Ta・VPD で条件付けると
    その分が吸収される、(c) **GEP・GER は実測でなく、NEE から光応答モデルで分割した派生量**なので、
    Rg との関係は分割法に一部組み込まれている（解釈に注意）。
  - だから「GEP は放射に無関係」ではない——**ペアワイズの I(Rg;GEP) は強い**（気候応答 fig1 の主指標）。
    頑健に残る炭素リンクは **GEP→NEE（光合成→正味 CO₂ 交換）**。
- **本質（これだけ言えば良い）**：**共通原因（放射）と間接経路を差し引くと、本物の直接因果はごく少数に
  絞られる（＝疎な骨格）。残るのは「放射→エネルギー・気象・地温」と「光合成→正味炭素」という骨組み。**

### fig4_robustness（年をまたいだ安定性）
- **縦軸**：そのリンクが **21年のうち何 % の年で出現したか**（＝頻度 = 出現年数 / 有効年数）。
- **"Physical core link" の閾値はどう決めたか**：**頻度 ≥ 70 %** かつ **矢印の先が Rg でない**もの。
  - 70 % は「**年をまたいで安定**」の慣用的カットオフ（恣意性はあるが、本物の因果は連続的に出続け、
    偶然の偽陽性は散発、という前提に基づく）。
  - 赤（アーティファクト）＝**矢印が Rg に入るもの（→Rg）**。放射は**外生**（生態系の中の何ものも入射
    日射を作らない）ので**物理的に不可能**→**頻度によらず偽陽性の目印**。つまり赤は"閾値"でなく"物理"で判定。

## 2. この3図を見せるために必要な「データ・変数・手法」（結果スライドの脚注/1枚）

**データ**
- JapanFlux2024（渦相関フラックス、FLUXNET2015 系）。サイト＝**JP-Tak（高山・冷温帯 落葉広葉樹林）**。
- 期間＝**1999–2021 の健全な21夏**、**30分値**、対象月＝**7–8月**（生育最盛期）。

**変数（R&K の11変数）**
- Rg 下向き短波放射／Ta 気温／VPD 飽差／Ts 地温／P 降水／θ 表層土壌水分／γH 顕熱／γLE 潜熱（蒸発）／
  GER 生態系呼吸／NEE 正味CO₂交換／GEP 総一次生産（光合成）。
- ※ GER・GEP は NEE から分割した**派生量**（実測は NEE）。

**前処理**
- **5日前方窓アノマリ**（日周期を除去し、天候変動だけを残す）。
- **11変数が同時に揃う時刻のみ使用**（listwise deletion）。

**手法（図ごと）**
- fig2b：相互情報量 I と**条件付き相互情報量 I(X;Y|Rg)**。**11ビン固定**、規格化 I′=I/log(11)、
  有意性は**シャッフル・サロゲート**（片側 α=0.01）。
- fig3：**PCMCI+**（tigramite）。tau_max=6（＝3時間）、pc_alpha=0.01、線形 ParCorr。
  graph の `-->` を有向因果とみなす。
- fig4：**各年で PCMCI+ を回し**、(src→dst) の**出現頻度**を集計。**頻度≥70% かつ 非→Rg** をコア、
  **→Rg** をアーティファクトとする。

**正直な注記（スライドの隅に一言）**
- GEP/GER は派生量（NEE 分割）。fig4 は**単一サイトの"時間"方向の頑健性**（複数サイトの空間的普遍性は
  別の解析で確認）。

## 3. 研究の背景と、卒論 → 修士の展望（やりたい・できるといいな）

### 背景（短く）
- 地球は実験できないので、**観測から因果や機構を読む**しかない。だが**相関では、同じ要因が一斉に動かす
  "見かけのつながり"**が出て、本当の因果と区別できない。そこで**情報理論＋因果推論**で、生態系の中の
  はたらき（光合成・呼吸・蒸発など）どうしの**因果の構造**を読む。

### 卒論（できたこと＝この3図）
- **日本の森林（JP-Tak）で、共通原因（放射）を差し引くと"疎で頑健な因果の骨組み"が残る**ことを示した
  （fig2b：見かけのフラックス結合は放射の影／fig3：疎な因果骨格／fig4：21年で安定）。
- 一言：**「相関の先の"因果の構造"を、東アジアのフラックス観測から読めることを実証した。」**

### 修士（延長線でやりたいこと・できるといいな）
1. **高次へ**：2つずつ（ペア）の先へ。**O-information で「3つ以上が組んで初めて効く（相乗）」を測る**。
   自然生態系の地下（土壌水分×温度×呼吸）に相乗があるか等。
2. **空間・管理へ**：多サイト・多生態系へ広げ、因果骨格の**普遍性**を確かめ、**人の土地管理（水田の湛水
   など）が結合構造をどう変えるか**を見る。
3. **気候勾配へ**：A3（日中韓）の**乾燥・大陸性サイト**で、乾燥ストレスに情報構造がどう応答するか。
4. **モデルとの対決**：呼吸・光合成モデルが仮定する**"相互作用の形"を観測から吟味**する。

### 研究室の利点を生かす（観点の例・当てはまるものを選ぶ）
- **A3（日中韓）で共有される東アジアのフラックスデータ／AsiaFlux ネットワークへのアクセス**を持つなら、
  湿潤日本の外（乾燥・大陸）まで気候勾配を広げられる＝修士の②③に直結。
- **長期の日本サイト**（20年級）を扱えるなら、年々変動・頑健性の検証に強い。
- **渦相関・生態系プロセスの専門性**があるなら、情報理論の結果を機構（呼吸・気孔）で裏づけられる。
- （もし**陸面モデル**の経験があれば、修士④「モデルとの対決」に直結。）
