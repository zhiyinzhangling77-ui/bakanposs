# 解析結果ノート — JapanFlux2024 プロセスネットワーク（3 サイト対比）

Ruddell & Kumar (2009) の情報理論プロセスネットワーク解析を JapanFlux2024 の
3 サイト（落葉樹林・水田・湿原）に適用した結果のまとめ。手法の詳細は
[`README.md`](README.md) を参照。

## 対象

| サイト | 生態系 | 期間 | n_points |
|---|---|---|---|
| JP-Tak | 冷温帯落葉広葉樹林 | 2003 年 7–8 月 | 2976 |
| JP-Mse | 水田（イネ） | 2003 年 7–8 月 | 2976 |
| JP-BBY | 湿原（ボッグ） | 2015 年 7–8 月※ | 2976 |

※ JP-BBY は観測開始が 2012 年のため 2003 年が無く、健全初年の 2015 年を採用。

いずれも COREVARS HH（30 分値・ギャップフィル済み）、5 日前方窓アノマリ、
固定ビン m=11、shuffled surrogate 有意性（α=0.01 片側, c=2.36）、ラグ 0.5–18 h、
多重比較補正 `peak_min_run=2`（2 連続有意帯を要求）。

## 主要な結合（7+8 月プール, n=2976, `peak_min_run=2`）

| ペア | JP-Tak 森林 | JP-Mse 水田 | JP-BBY 湿原 |
|---|---|---|---|
| VPD→γLE | type 2 (Tz=0.24) | type 1 | type 2 (Tz=0.31) |
| GEP→NEE | type 2 (Tz=0.24) | type 2 (Tz=0.14) | type 2 (Tz=0.33) |
| Ts→GER | type 1 | type 1 | type 1 |
| P→θ | type 1 | type 1 (I'=2.7%) | type 1 |
| **forcing (type 3)** | **無** | **無** | **無** |

- type 1 = 同期（I 有意・T 非有意）, type 2 = フィードバック（T 有意・Tz<1）,
  type 3 = 強制（T 有意・Tz>1）, type 4 = 無結合。
- 盤面はほぼ全面 type 1（sync）。有向流（type 2）は放射・生産・乱流フラックス間の
  最短ラグ（0.5 h）に限られ、**type 3（遅延強制）は 3 サイトいずれも検出されず**。

## 結論: 3 生態系すべて「同期支配」

maritime-monsoon 気候下の日本 3 サイトでは、sub-5-day アノマリ空間の情報構造は
**同時的結合（同期）が支配**し、R&K が大陸性畑作（Bondville）で見出した遅延強制の
連鎖は現れない。唯一頑健な有向流は **GEP→NEE（0.5 h, 全サイト共通）**。

### この結論が頑健である根拠

1. **ビン数に不変**: m=11 と m=8 で JP-Tak のトポロジは実質同一。
2. **多重比較補正で偽陽性を除去**: 単月・`peak_min_run=1` で現れた JP-Tak の
   P→γH type 3（6.0 h）は、`peak_min_run=2` で消える。P と γH は実質無結合
   （I≈0）で、36 ラグ走査中に T が偶発有意化 → Tz=T/I 発散という教科書的な
   多重比較偽陽性。実データで補正の必要性を実証。
3. **検出力不足を棄却（決定的）**: n を 1488→2976 に倍増しても forcing は出ず、
   Tz はむしろ低下（JP-Tak VPD→γLE: 0.47→0.24）。floor を下げれば強制が浮くはず
   という仮説と逆 → 単月の Tz は有限標本バイアスの水増しであり、真の有向流は
   I に対してさらに小さい。「forcing が floor に隠れている」可能性は否定される。

### 生態系の指紋

- **水田 (JP-Mse)** が最も同期的（有向流が最少）。**P→θ の I'≈2.7% と極端に低い**
  のは、湛水灌漑で表層土壌水分がほぼ一定 → 情報を持たず、降水→土壌水分の結合が
  消えるため。水管理の直接的な現れ。
- **森林・湿原** は VPD→γLE と GEP→NEE に有向流を持つ点で共通。

## 残る留意点（discussion 用）

- **ギャップフィルによる I 膨張**: COREVARS は MDS 補完済み。補完値は類似気象条件
  からの内挿なので変数間に人工的な共有構造（I）を持ち込みやすく、2 次元 I は
  上がりやすい一方 3 次元 T は上がりにくい → **type 1（sync）側へバイアス**する
  恐れ。決定的検証には `_QC` で実測（QC=0）に絞った再解析が要るが、11 変数の
  listwise で n が激減するトレードオフがある。
- **推定器の疎性**: m=11 の 3 次元同時ヒストは 11³=1331 セル。n=2976 でも
  ~2 点/セルで、絶対 TE でなくサロゲート有意性で判定する必要がある（実装済み）。
