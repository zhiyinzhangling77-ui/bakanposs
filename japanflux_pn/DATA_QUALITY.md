# データの分類と品質基準 — 何を、なぜ、どう使うか（理由つき）

本研究が使う渦相関フラックスデータについて、**(1) どんな種類があるか（分類）**、
**(2) 品質をどう判定し何を採るか（基準と理由）**、**(3) 実際どれくらい測れているか（限界）**
を、コード（`rank_sites.py`・`ecosystem.py`・`preprocess.py`・`sites.py`）で確認した事実に基づき記す。
数値は `rank_sites`（全サイト走査）と O-info atlas（21サイト実行）の実出力から。

---

## 0. データの出所（3データセット）

- **JapanFlux2024**（日本中心、FLUXNET2015 系の `_F`/`_MDS` 整形）
- **ChinaFlux**（中国、年別 xlsx）
- **KoFlux**（韓国、BASE 形式 xlsx）
形式差は `preprocess`/`sites` がコードで吸収（情報量は単調変換・符号反転・単位に不変なので
中国 NEP=−NEE もそのまま使える）。全走査で **83 サイト**を検出。

## 1. 使えるデータの分類

### 1-1. まず「使える／使えない」の壁（11変数マッピング）
本研究は R&K の **11変数** {Rg, Ta, VPD, Ts, P, θ, γH, γLE, GER, NEE, GEP} を使う
（因果骨格・O-info サブ系のため）。11変数が揃わないと呼吸系 {Rg,Ta,θ,GER} 等が組めない。

| | サイト数 | 中身 |
|---|---|---|
| **11/11 揃う（使える）** | **31** | 解析対象 |
| 変数欠測（使えない） | 52 | 大半が **θ(土壌水分) 欠測**、次いで Ts、一部は炭素も欠測 |

→ **最大の壁は "土壌水分 θ を測っていないサイトが半分以上"**（52/83）。θ が無いと呼吸・土壌系の
高次解析は原理的に不可能。＝「観測されていない」が具体的にどこかを示す一次事実。

### 1-2. 使える 31 サイトの生態系分類（IGBP／`ecosystem.py`）
（★=BADM 確定、他は AsiaFlux/JapanFlux 公表情報に基づく粗分類。健全年数は O-info atlas 実行値）

| 生態系グループ | サイト（健全年数） |
|---|---|
| **落葉広葉樹林 DBF** | JP-Tak★(21) |
| **常緑針葉樹林 ENF** | JP-Ta2★(11) |
| **落葉針葉樹林 DNF（シベリア・カラマツ）** | RU-Ege(8)・RU-SkP(7) |
| **森林（詳細 IGBP は要 BADM 確認）** | JP-Tef(20)・JP-Fhk(18)・JP-Tmd(18)・JP-SMF(12)・JP-Spp(11)・JP-Fjy(10)・JP-MMF(9)・JP-MBF(8)・JP-Ynf(8)・JP-Yms(6)・CN-Lsh(4)・TH-Mae(8, 熱帯) |
| **草原 GRA** | CN-HaM★相当(10, 青海高山)・MN-Kbu(5)・MN-Nkh(5)・MN-Hst(8相当)・MN-Skt(8相当) |
| **農地 CRO（水田・湛水）** | JP-Mse★(8) |
| **湿地 WET** | JP-BBY★(5, 泥炭湿原) |

### 1-3. 気候帯の広がり
温帯モンスーン（日本の森林多数）／大陸性乾燥（モンゴル草原・中国高山）／
亜寒帯（ロシア・カラマツ）／熱帯（タイ TH-Mae）。＝**熱帯〜亜寒帯を跨ぐ**（O-info 背骨の普遍性を
21サイトで言える根拠）。ただし**日本の温帯森林に強く偏る**（長期＝日本、他は短期・少数）。

## 2. 品質基準 — 何を採り、なぜそうするか

### 基準A：11変数が listwise で揃う時刻のみ使う
- **やること**：ある時刻に11変数が全部あるときだけ採る（1つでも欠測ならその時刻を捨てる）。
- **なぜ**：相互情報量・PCMCI・O-info は**同時刻の値の同時分布**を使う。1変数でも欠ければ
  その時刻の高次分布は作れない。＝情報・因果解析の原理的要請。

### 基準B：健全な「site-year」＝夏に十分な点数が listwise で残る年
- **やること**：各年の 7–8月で、listwise 後の点数が **500〜1500点**に収まる年を「健全」と数える
  （`rank_sites`）。
- **なぜ**：(下限) 点数が少なすぎると MI/O-info/PCMCI の推定が偶然に支配される（検出力ゼロ）。
  (上限) 逆に多すぎ＝ほぼ gap-fill で埋めた年は「実測の年」として過大評価しないため上限も置く。
  ＝**検出力は"名目の観測年数"でなく"実際に揃った点数"で決まる**、を厳密に測る設計。
- **結果**：11/11 サイトの健全 site-year 総数 = 472（×2月）。**長期は JP-Tak(21年) が突出**、
  多くは 5〜11年。→「サイトあたり年数不足」という本研究最大の限界の正体。

### 基準C：夏（7–8月）を対象・5日前方窓アノマリ
- **なぜ夏**：生育最盛期で炭素・水・エネルギー交換が活発＝結合が最も見える。
- **なぜ5日アノマリ**：一日周期（Rg–GPP の最強の連動）を除き、**天候変動（本研究が見たい因果）**を残す。
  ※絶対値の応答（Q10・モデル形）を見る解析は生の絶対値を使う（アノマリでは温度応答が消えるため。旗23-26）。

### 基準D：gap-fill と QC（"実際どれくらい測れているか"の核心）
- **既定は gap-fill 込み**（FLUXNET LEVEL-4, `_F`/`_MDS` 列）＝**欠測はモデル(MDS等)で埋めた値**が入る。
  - **なぜ既定で使うか**：R&K/FLUXNET の標準運用。点数を確保でき、気象は高品質。
- **GER/GEP は実測でなく分割派生量**（RECO_DT/GPP_DT を NEE から昼/夜分割で作る）。自前 QC が無いので
  NEE の QC を継承。
- **QC≤1（実測寄り）に絞れる**（`--qc-max 1`）＝低品質 gap-fill を NaN 化。
  - **なぜ用意するか**：発見が"穴埋め由来でない"かを検証するため。実測被覆は
    **森林 JP-Tak で 71%（炭素の約29%が穴埋め）／水田99%・湿原98%**。森林の炭素が最も穴埋めが多い
    （乱流が弱く夜間 NEE が棄却されやすい）。
  - **実際に検証済み**：呼吸の未観測(旗25)・水分依存Q10(旗26)は QC≤1 でも不変＝穴埋め由来でない。

## 3. 使い分けの階層（"使えるか"を検出力で段付け）

| ティア | 健全年数 | 使える解析 | サイト例 |
|---|---|---|---|
| **A（長期）** | ≥10年 | 何でも（大きさ・状態依存の相関・O-info多年安定） | JP-Tak・JP-Tef・JP-Fhk・JP-Tmd・JP-SMF・JP-Spp・JP-Ta2・JP-Fjy・CN-HaM |
| **B（中期）** | 5〜10年 | **方向性・符号**（O-info符号・Q10の向き）は可、大きさは慎重に | RU/MN/TH/水田/湿原 等 |
| **C（短期）** | <5年 | 参考のみ（検出力不足を明示、結論に使わない） | CN-Lsh 等 |

- **なぜ段付けるか**：同じ解析でも「大きさ」は年数（＝(Ta,θ)被覆）に敏感で underpower になるが、
  「向き・符号」は少ない年数でも検出できる（旗21 vs 旗27 の対比で実証）。＝**発見の種類ごとに
  必要な品質が違う**。だから「全部を全サイトで」でなく「向きの解析を全サイトで」が正しい多サイト化。

## 4. 正直な限界（このデータで言えないこと）

1. **θ/Ts 欠測が 52/83 サイト**＝呼吸・土壌の高次解析は 31 サイトに限られ、しかも θ の質・深さは不均一。
2. **長期は日本の温帯森林に偏る**（JP-Tak 21年が突出）。熱帯・亜寒帯・乾燥は少数・短期。
3. **炭素は派生量**（GER/GEP は NEE 分割）＋森林で約3割が gap-fill。QC≤1 で主要発見は不変を確認済みだが、
   "分割モデルのアーティファクト"は QC では消せない（独立測定＝チャンバーが要る）。
4. ＝**「観測を増やす（衛星プロキシ・θの多点/深層・独立呼吸測定）」が要る**、を具体的に根拠づける。

## 5. θ欠測サイトは救えるか（変数構成による救済の検討）

θ(土壌水分)欠測で除外した 52 サイトのうち **約19は θ だけが欠測（10/11）**（内モンゴル草原 CN-In1〜8、
JP-Hc1/Km2/Nuf 等）。これらを「θ を使わない発見」に限れば救える。**発見ごとに θ 依存が分かれる**：

| 発見 | θ が要るか | θ欠測サイトで救えるか |
|---|---|---|
| 冗長の背骨：光合成{Rg,Ta,VPD,GEP}・炭素コア{Rg,GEP,GER,NEE}・エネルギー{Rg,Ta,γH,γLE} | **不要** | ✅ 救える |
| 光利用の脱結合 I(Rg;GEP) vs VPD | 不要 | ✅ 救える |
| 光合成のモデル形 GEP(Rg,VPD) | 不要 | ✅ 救える |
| 因果骨格（θリンク以外） | θ以外は不要 | ✅ 部分的に |
| 呼吸の相乗 {Rg,Ta,θ,GER}・水分依存Q10・θ→GER・呼吸モデル形・土壌熱 | **必要** | ✗ 救えない |

- **意味**：放射共通駆動の背骨と光合成側は θ 無しで救え、**使えるサイトが 21→約40 にほぼ倍増**
  （内モンゴル草原など生態系多様性も増え、背骨の普遍性を更に盤石にできる）。呼吸・土壌は θ が主役なので救えない。
- **実装の見積もり**：`RK_VARS`（11変数固定）が読み込み全体に import されているため、θ抜き10変数で回すには
  **「変数セットを可変にする」小改修（config化）**が要る。難しくないがモジュール横断＝独立タスク。
- **＝救済は原理的に可能・価値あり（背骨/光合成のサイト倍増）だが、呼吸・土壌の発見には無効**。θ の観測を
  増やすこと自体が、呼吸の研究には代替不能（＝「観測を増やす」動機の再確認）。

## 6. 今のフィルタは足りない — QC が"見ていない"品質と、更に絞る観点（重要・正直）

現行フィルタ（基準A–D）は**入口**に過ぎない。コードで確認した限界：

### 6-1. 私たちの QC は「乱流検定」であって「測定 vs 穴埋め」ではない
- 使っている QC フラグは **`_SSITC_TEST_`（steady-state + integral turbulence test, 0/1/2）＝乱流の定常性検定**。
  `--qc-max 1` は「乱流検定ほどほど以上」を意味するだけで、**gap-fill か実測かの区別ではない**。
- さらに**炭素フラックスは可変 u* 閾値 `_vUT` で既にフィルタ済み**＝**乱流の弱い夜間は除去され、モデルで
  穴埋めされてから GER/GEP に分割**される。派生炭素の QC は CO2 乱流フラックスの SSITC を代理に使うだけ。
- ＝**「呼吸(GER)」は特に夜間、実質モデル出力**。SSITC ではこれを捕まえられない。**これが旗25 で
  「未観測 or 分割アーティファクト」が割れなかった根本理由**（呼吸の夜間がそもそも観測でなくモデルだから、
  フラックスだけでは原理的に割れない）。

### 6-2. まだ絞れていない品質の観点（更に厳しくする余地）
| 観点 | 現状 | なぜ効くか |
|---|---|---|
| **u* フィルタ（夜間乱流）** | データに `_vUT` で焼き込み・私たちは未確認 | 夜間呼吸の測定/穴埋めを分ける最重要点 |
| **QC の厳しさ** | ≤1 | **=0（最良乱流のみ）に絞れる**（`--qc-max 0`, 未実施） |
| **エネルギー収支 closure**（H+LE vs Rn−G） | 未チェック | closure 不良＝系統的フラックス過小、サイト品質の定番指標 |
| **storage 補正** | データ依存 | 未補正だと NEE が偏る |
| **分割法（DT vs NT）** | DT のみ | 昼分割/夜分割で GER が変わる＝どちらも"真値"でない（要 config 小改修で比較可） |
| **ランダム誤差** | 未考慮 | 低フラックス時は相対誤差が大 |
| **派生変数** | VPD=TA+RH／GER/GEP=NEE 分割 | "観測値"自体が一部モデル |
| **降雨時** | EC 不能→穴埋め | 濡れたセンサーは測れない |

### 6-3. 結論（誠実に）
現行フィルタは**"入口の乱流検定"に過ぎず、深い品質管理には足りない**。特に**呼吸は夜間 u* フィルタ＋穴埋め
＋分割で作られる＝観測でなくモデル寄り**——これが呼吸の全発見（相乗・非加法・水分依存Q10・未観測）に乗る
**最も深い留保**。強化の道：(1) `--qc-max 0`（最厳の乱流検定）で発見が生き残るか、(2) DT vs NT 分割の感度、
(3) 究極は**独立測定（チャンバー呼吸・u* 直接・エネルギー収支）＝タワー外のデータ**＝「観測を増やす」の最も具体的な中身。
＝**フィルタを厳しくするほど、"フラックスタワーのデータだけでは呼吸の真値に届かない"が鮮明になる**。
